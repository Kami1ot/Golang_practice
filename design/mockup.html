Переменные и типы

var, :=, базовые типы, нулевые значения, ввод через fmt.Scan

Переменная (variable) — именованная ячейка для значения. Go — язык со статической типизацией: тип известен при компиляции и не меняется.

Короткая форма :=

package main

import "fmt"

func main() {
    age := 25          // объявление + присваивание
    fmt.Println(age)
}
i:= работает только внутри функций. На уровне пакета — полная форма var.
!Повторное age := 30 в том же блоке — ошибка компиляции. Изменить значение — просто age = 30.
Вопрос 1 · один вариант

Чем := отличается от =?

✓Верно. := — только внутри функций.
Вопрос 2 · что выведет код

Что выведет эта программа?

var n int
fmt.Println(n)
✕Нулевое значение (zero value) для int — это 0, а не nil.

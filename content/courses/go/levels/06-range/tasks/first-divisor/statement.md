Прочитайте целое число `n` (2 ≤ n ≤ 1 000 000) и выведите его **наименьший делитель, больший единицы**.

Если `n` — простое число (*prime*), таким делителем окажется само `n`.

Пример:

```
Ввод:  15
Вывод: 3
```

15 делится на 3 и на 5; наименьший из делителей — 3.

Задача **со звёздочкой**. Она тренирует идиому «нашли — выходим»: без `break` цикл будет печатать все делители подряд, а нужен только первый.

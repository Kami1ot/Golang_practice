# Переменные и типы

Переменная (*variable*) — именованная ячейка памяти, в которой лежит значение. Почти любая программа — это переменные плюс операции над ними, так что тема сегодняшнего уровня будет с вами до конца курса.

## Статическая типизация: контракт с компилятором

Go — язык со статической типизацией (*static typing*): у каждой переменной есть тип (*type*), он известен уже при компиляции и **никогда не меняется**. Это контракт: «в `age` лежит целое число — и точка». Попытка положить туда строку даже не скомпилируется:

```go
var age int = 25
age = "двадцать пять"
// Ошибка компиляции:
// cannot use "двадцать пять" (untyped string constant) as int value in assignment
```

В Python такой баг дожил бы до запуска. В Go — умирает на месте. Чем больше программа, тем ценнее эта строгость.

## Объявление: полная форма var

```go
var age int = 25
var name string = "Гоша"
var height float64 = 1.78
var isAdmin bool = false
```

Схема: `var имя тип = значение`. Тип пишется **после** имени — непривычно после C или Java, зато читается как фраза: «переменная `age` типа `int`».

Тип можно опустить — компилятор выведет его из значения сам (вывод типа, *type inference*):

```go
var age = 25        // int
var name = "Гоша"   // string
var height = 1.78   // float64
```

Несколько переменных одного типа — в одну строку, а связанные объявления — в блок:

```go
var width, height int = 1920, 1080

var (
    appName = "GoPractice"
    version = 2
)
```

## Короткая форма :=

Внутри функций чаще пишут короче — оператор `:=` объявляет переменную **и** присваивает значение, тип выводится автоматически:

```go
age := 25          // int
name := "Гоша"     // string
pi := 3.14         // float64
ok := true         // bool
```

Два правила:

1. `:=` работает **только внутри функций** (на уровне пакета — только `var`).
2. `:=` — объявление **новой** переменной; для изменения существующей нужен обычный `=`.

```go
score := 10   // объявили
score = 15    // изменили (уже без двоеточия!)
score := 20   // ошибка: no new variables on left side of :=
```

> [!WARNING]
> `:=` против `=` — ошибка новичка номер один. Запомните так: двоеточие — «рождение» переменной, и родиться она может только один раз.

## Несколько переменных сразу и обмен значениями

Go умеет присваивать пачкой — и это не синтаксический сахар, а рабочая идиома:

```go
a, b := 3, 4
fmt.Println(a, b)
// Вывод: 3 4

a, b = b, a   // обмен значениями — без временной переменной!
fmt.Println(a, b)
// Вывод: 4 3
```

Правая часть вычисляется целиком **до** присваивания, поэтому обмен работает честно.

## Базовые типы

Четыре типа, которых хватит на ближайшие уровни:

| Тип | Что хранит | Примеры значений |
|---|---|---|
| `int` | целые числа | `42`, `-7`, `0` |
| `float64` | дробные числа | `3.14`, `-0.5` |
| `string` | текст в UTF-8 | `"привет"`, `""` |
| `bool` | логическое значение | `true`, `false` |

### Обзорно: семейство числовых типов

У `int` есть родственники с фиксированным размером — они понадобятся позже, но знать об их существовании стоит уже сейчас:

| Типы | Что это |
|---|---|
| `int8`, `int16`, `int32`, `int64` | целые со знаком: число — размер в битах (`int8`: от −128 до 127) |
| `uint`, `uint8` ... `uint64` | целые **без знака** (*unsigned*): только ≥ 0, зато диапазон вдвое шире |
| `float32`, `float64` | дробные одинарной и двойной точности |

Практическое правило: для целых — `int`, для дробных — `float64`. Остальные — для особых случаев (экономия памяти, бинарные форматы). Именно эти два типа Go подставляет при `:=`.

## Нулевые значения

В Go **не бывает** неинициализированных переменных с мусором внутри. Объявили без значения — получили нулевое значение (*zero value*) типа:

```go
var n int
var f float64
var s string
var b bool
fmt.Println(n, f, s, b)
// Вывод: 0 0  false
```

| Тип | Нулевое значение |
|---|---|
| `int`, `float64` | `0` |
| `string` | `""` — пустая строка |
| `bool` | `false` |

Заметьте в примере два пробела между `0` и `false`: там напечаталась пустая строка `s`.

## Конверсия типов: только явно

Go **никогда** не преобразует числовые типы неявно. Сложить `int` с `float64` напрямую нельзя:

```go
count := 3          // int
price := 99.5       // float64
total := count * price
// Ошибка компиляции:
// invalid operation: count * price (mismatched types int and float64)
```

Нужна явная конверсия (*type conversion*) — вызов типа как функции:

```go
total := float64(count) * price
fmt.Println(total)
// Вывод: 298.5
```

Работает в обе стороны, но с потерями при сужении:

```go
x := 3.99
fmt.Println(int(x))
// Вывод: 3   (дробная часть ОТБРАСЫВАЕТСЯ, не округляется!)
```

> [!WARNING]
> Деление целых даёт целое: `7 / 2` — это `3`, а не `3.5`. Хотите дробный результат — сначала конвертируйте: `float64(7) / 2` даст `3.5`. Эта граната срабатывает у каждого второго новичка.

Почему так строго? Неявные конверсии — источник тихих багов в C-подобных языках (внезапные округления, переполнения). Go требует, чтобы каждое преобразование было видно в коде глазами.

## Константы

Константа (*constant*) — имя для значения, которое не меняется никогда. Объявляется словом `const`:

```go
const Pi = 3.14159
const AppName = "GoPractice"

Pi = 3.0
// Ошибка компиляции: cannot assign to Pi
```

Для пронумерованных констант есть счётчик `iota` — он выдаёт 0, 1, 2... внутри блока:

```go
const (
    Low    = iota // 0
    Medium        // 1
    High          // 2
)
```

Пока просто узнавайте эту конструкцию в чужом коде — активно пользоваться ей будем в уровне про типы.

## Ввод данных: fmt.Scan

Пора научить программы слушать. `fmt.Scan` читает значения из ввода (разделённые пробелами или переводами строк) и раскладывает их по переменным:

```go
package main

import "fmt"

func main() {
    var a, b int
    fmt.Scan(&a, &b)   // ввод: 3 4
    fmt.Println(a + b)
    // Вывод: 7
}
```

Перед каждой переменной — амперсанд `&`: он передаёт **адрес** переменной, чтобы `Scan` мог записать значение внутрь неё. Подробно про адреса поговорим в уровне про указатели — пока просто правило: **в `Scan` переменные передаются с `&`**.

`Scan` понимает тип сам: в `int` прочитает число, в `string` — слово (до пробела), в `float64` — дробное:

```go
var name string
var age int
fmt.Scan(&name, &age)   // ввод: Гоша 25
fmt.Println(name, "-", age)
// Вывод: Гоша - 25
```

## Типичные ошибки новичка

### 1. Объявил и не использовал

```go
func main() {
    x := 42
}
```

```
declared and not used: x
```

**Почему:** неиспользуемая локальная переменная в Go — ошибка компиляции. Мёртвый код не накапливается. **Как чинить:** удалить переменную или использовать её. На время отладки можно написать `_ = x` — «пустой» идентификатор съедает значение (вы уже видели этот приём в заготовках задач).

### 2. Тип из другого языка

```go
int x = 5
```

```
syntax error: unexpected name x at end of statement
```

**Почему:** это синтаксис C/Java, парсер Go на нём спотыкается. **Как чинить:** в Go — `var x int = 5` или `x := 5`; тип всегда после имени.

### 3. Забытый & в Scan

```go
var n int
fmt.Scan(n)   // компилируется, но работает неправильно!
```

Компилятор здесь молчит — это самое коварное. Но `Scan` получит **копию** нуля вместо адреса переменной: записать значение ему некуда, `n` останется `0`, а ошибку `type not a pointer`, которую возвращает `Scan`, мы пока не проверяем. **Как чинить:** `fmt.Scan(&n)` — всегда с амперсандом; увидели «программа игнорирует ввод» — первым делом ищите потерянный `&`.

## Запомнить

- Тип переменной фиксируется при компиляции и не меняется — это статическая типизация.
- `var имя тип = значение` — полная форма; `имя := значение` — короткая, только внутри функций.
- `:=` объявляет новую переменную, `=` присваивает существующей.
- `a, b = b, a` — обмен значениями без временной переменной.
- Рабочие типы: `int`, `float64`, `string`, `bool`; у чисел есть семейства `int8..64`, `uint`, `float32`.
- Нет мусора — есть нулевые значения: `0`, `0.0`, `""`, `false`.
- Смешивать типы в выражениях нельзя: конвертируйте явно — `float64(n)`, `int(x)`; `int(3.99)` — это `3`.
- Деление целых — целое: `7/2 == 3`; для дробного результата конвертируй до деления.
- `const` — неизменяемое значение; `iota` нумерует константы в блоке.
- `fmt.Scan(&a, &b)` читает ввод; амперсанд обязателен.
- Неиспользованная переменная — ошибка компиляции; временно спасает `_ = x`.

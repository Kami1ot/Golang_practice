Прочитайте два целых числа из ввода и выведите их сумму.

**Ввод:** два целых числа через пробел.
**Вывод:** одно число — сумма.

Пример:

```
Ввод:  3 4
Вывод: 7
```

Числа могут быть и отрицательными — но для сложения это ничего не меняет.

Подсказка: объявите две переменные `int` и прочитайте их через `fmt.Scan(&a, &b)` — амперсанды обязательны.

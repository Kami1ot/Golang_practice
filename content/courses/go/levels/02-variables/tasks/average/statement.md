Прочитайте два целых числа и выведите их среднее арифметическое одним вызовом `fmt.Println`.

**Ввод:** два целых числа через пробел.
**Вывод:** среднее арифметическое — возможно, дробное.

Пример:

```
Ввод:  3 4
Вывод: 3.5
```

Главная хитрость: сумма двух `int` — тоже `int`, и обычное деление на 2 отбросит дробную часть. Вспомните из урока, как получить **дробный** результат деления.

Если среднее целое (например, для `2 2`), `fmt.Println` сам напечатает его без дробной части: `2` — так и должно быть, ничего дополнительно делать не нужно.

Задача **необязательная** — но конверсия типов будет встречаться вам постоянно.

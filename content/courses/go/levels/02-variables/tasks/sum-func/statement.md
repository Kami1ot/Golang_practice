Реализуйте функцию `Sum(a, b int) int`, которая возвращает сумму двух чисел.

Это первая задача, где вы пишете **функцию**, а не программу целиком: `func main` здесь не нужен, вашу функцию вызовут автотесты (*unit tests*) — с самыми разными аргументами: положительными, отрицательными, нулями.

```go
Sum(3, 4)   // 7
Sum(-2, -3) // -5
Sum(0, 0)   // 0
```

Не меняйте имя и сигнатуру функции — тесты ищут именно `Sum(a, b int) int`.

Разогрев на распаковку. На первой строке — число `n` (0 ≤ n ≤ 100), на второй — `n` целых чисел через пробел. Прочитайте числа в слайс, реализуйте вариативную функцию

```go
func Sum(nums ...int) int
```

и выведите сумму всех чисел, передав слайс в функцию с распаковкой: `Sum(nums...)`.

Пример:

```
Ввод:  3
       1 2 3
Вывод: 6
```

При `n = 0` второй строки нет вовсе, а сумма пустого набора равна `0` — вариативная функция обязана спокойно переживать вызов без аргументов.

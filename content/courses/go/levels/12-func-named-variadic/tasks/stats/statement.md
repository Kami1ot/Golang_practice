Реализуйте функцию `Stats`, которая принимает любое число целых аргументов и возвращает сразу три именованных результата — минимум, максимум и сумму:

```go
func Stats(nums ...int) (min, max, sum int)
```

Примеры:

```go
Stats(3, 1, 4, 1, 5)   // 1, 5, 14
Stats(7)               // 7, 7, 7
Stats()                // 0, 0, 0
```

Правила:

- вызов без аргументов `Stats()` возвращает `(0, 0, 0)`;
- для одного числа все три результата равны ему самому;
- числа могут быть **отрицательными** — стартовать поиск минимума и максимума с нуля нельзя (ловушка из урока: берите за старт первый элемент);
- функцию будут вызывать и с распаковкой готового слайса `Stats(data...)` — если внутри вы работаете с `nums` как с обычным слайсом, ничего дополнительно делать не нужно;
- не меняйте имя и сигнатуру функции — тесты ищут именно `Stats(nums ...int) (min, max, sum int)`.

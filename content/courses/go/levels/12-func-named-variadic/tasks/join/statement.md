Задача со звёздочкой. Реализуйте функцию `Join`, которая склеивает строки через разделитель:

```go
func Join(sep string, parts ...string) string
```

Примеры:

```go
Join(", ", "a", "b", "c")   // "a, b, c"
Join("-", "го")             // "го"
Join("+")                   // ""
```

Правила:

- **`strings.Join` использовать нельзя** — весь смысл задачи в том, чтобы собрать строку самому, наивным циклом со склейкой `+`/`+=`;
- вызов без частей возвращает пустую строку, единственная часть возвращается как есть;
- разделитель ставится строго МЕЖДУ частями: ни в начале, ни в конце результата его быть не должно;
- разделитель может быть пустым, а части — кириллическими;
- не меняйте имя и сигнатуру функции — тесты ищут именно `Join(sep string, parts ...string) string`.

Обратите внимание на порядок параметров: разделитель — обычный первый параметр, вариативный `parts` — последний, как и положено variadic-параметру.

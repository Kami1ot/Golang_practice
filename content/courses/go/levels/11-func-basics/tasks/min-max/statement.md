Реализуйте функцию `MinMax(a, b, c int) (int, int)`, которая возвращает **два** значения: минимум и максимум из трёх чисел — именно в этом порядке.

```go
MinMax(3, 1, 2)    // 1, 3
MinMax(7, 7, 7)    // 7, 7
MinMax(-5, 0, 5)   // -5, 5
```

Требования:

- порядок результатов — (минимум, максимум), не перепутайте;
- числа могут быть отрицательными, могут частично или полностью совпадать;
- результат не должен зависеть от порядка аргументов: `MinMax(1, 2, 3)` и `MinMax(3, 1, 2)` дают одно и то же;
- не меняйте имя и сигнатуру функции — тесты ищут именно `MinMax(a, b, c int) (int, int)`.

`func main` писать не нужно — тесты вызовут функцию сами.

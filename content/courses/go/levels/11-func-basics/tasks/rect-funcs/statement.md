Разминка: первая программа с собственными функциями. Прочитайте два целых числа — ширину `w` и высоту `h` прямоугольника (одной строкой через пробел) — и напечатайте **две строки**: сначала периметр, затем площадь.

Обязательное условие: считать должны две отдельные функции, а `main` — только читать ввод и печатать их результаты:

```go
func Perimeter(w, h int) int   // периметр: 2·(w + h)
func Area(w, h int) int        // площадь: w·h
```

Пример:

```
Ввод:  3 4
Вывод: 14
       12
```

Стороны — целые числа от 0 до 200 000 (да, вырожденный прямоугольник с нулевой стороной тоже бывает).

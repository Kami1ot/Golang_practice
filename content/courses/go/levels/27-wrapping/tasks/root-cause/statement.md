Задача со звёздочкой: доберитесь до первопричины.

Ошибка приехала обёрнутой в несколько слоёв контекста. Иногда нужно узнать, с чего ВСЁ началось, — добраться до дна матрёшки. Реализуйте функцию:

```go
func RootCause(err error) error
```

Правила:

- `nil` — верните `nil`;
- ошибка без обёрток — верните её саму;
- цепочка обёрток — верните самую глубокую ошибку (ту, у которой `errors.Unwrap` возвращает `nil`).

Пример работы:

```go
base := errors.New("диск отвалился")
wrapped := fmt.Errorf("сохранение: %w", fmt.Errorf("запись файла: %w", base))

RootCause(wrapped) == base  // true — добрались до дна
RootCause(base) == base     // true — дно и было
RootCause(nil)              // nil
```

Готовой функции для этого в пакете `errors` нет — соберите её из цикла и `errors.Unwrap`. Заодно прочувствуете, как устроены `errors.Is` и `errors.As` изнутри.

Не меняйте имя и сигнатуру функции.

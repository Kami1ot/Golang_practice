Разминка: добавьте контекст, не потеряв исходную ошибку.

В заготовке уже есть известная ошибка и проверка (менять их не нужно):

```go
var ErrEmpty = errors.New("пустой ввод")

func Validate(s string) error // возвращает ErrEmpty для пустой строки
```

Реализуйте функцию:

```go
func Process(s string) error
```

Она вызывает `Validate` и:

- при ошибке — оборачивает её с контекстом: текст итоговой ошибки ровно
  `обработка: пустой ввод`;
- при успехе — возвращает `nil`.

Пример работы:

```go
err := Process("")
err.Error()                 // "обработка: пустой ввод"
errors.Is(err, ErrEmpty)    // true — исходная ошибка внутри!

Process("привет")           // nil
```

Ключевое требование: `errors.Is(err, ErrEmpty)` должно возвращать `true` — то есть оборачивать нужно правильным глаголом.

Не меняйте объявление ErrEmpty, функцию Validate, имя и сигнатуру Process.

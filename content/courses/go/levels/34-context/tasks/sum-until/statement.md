Основная задача: напишите горутину-работника «как в настоящем сервисе» — она обслуживает поток данных и мгновенно сворачивается по просьбе.

Реализуйте функцию:

```go
func SumUntil(ctx context.Context, ch <-chan int) int
```

Она суммирует значения из канала и возвращает накопленную сумму, когда случится **любое** из двух событий:

- канал закрыт (данные кончились) — вернуть сумму всех принятых значений;
- контекст отменён — немедленно вернуть то, что успело накопиться.

Пример работы:

```go
ch := make(chan int)
ctx, cancel := context.WithCancel(context.Background())

go func() {
	ch <- 1
	ch <- 2
	cancel() // просим остановиться
}()

SumUntil(ctx, ch) // 3 — приняли 1 и 2, дальше отмена
```

Требования: один цикл `for` + `select` с двумя ветками; закрытие канала ловите ok-идиомой приёма. Функция не должна ни зависать после отмены, ни крутиться вхолостую.

Не меняйте имя и сигнатуру функции.

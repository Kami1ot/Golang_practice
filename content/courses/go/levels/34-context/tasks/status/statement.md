Разминка: научитесь спрашивать контекст о его судьбе — не задерживаясь.

Реализуйте функцию:

```go
func Status(ctx context.Context) string
```

Она **мгновенно** (без блокировки!) возвращает:

- `отменено` — если контекст уже отменён;
- `работаем` — если контекст жив.

Пример работы:

```go
ctx, cancel := context.WithCancel(context.Background())

Status(ctx) // "работаем"
cancel()
Status(ctx) // "отменено"
```

Сигнал отмены — закрытие канала `ctx.Done()`: приём из закрытого канала готов немедленно, а у живого контекста — блокирует. Соедините это с неблокирующим select из уровня про буферы — и задача решена в пять строк.

Не меняйте имя и сигнатуру функции.

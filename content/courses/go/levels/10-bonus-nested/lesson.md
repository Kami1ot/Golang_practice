# Бонус: вложенные циклы — цикл в цикле

Один цикл перебирает строку чисел. А если данные двумерные — таблица, шахматная доска, все пары игроков турнира? Тогда внутрь одного цикла кладут второй. Это вложенные циклы (*nested loops*) — приём простой, но с парой сюрпризов.

## Как это работает

Внутренний цикл прокручивается **целиком** на каждой итерации внешнего:

```go
for i := 1; i <= 3; i++ {
    for j := 1; j <= 2; j++ {
        fmt.Println(i, j)
    }
}
// 1 1
// 1 2
// 2 1
// 2 2
// 3 1
// 3 2
```

Внешний счётчик `i` сделал 3 шага, внутренний `j` — по 2 шага на каждый. Тело выполнилось 3 × 2 = **6 раз**. Запомните это умножение — оно ещё сыграет роль.

## fmt.Print против fmt.Println

Для рисования фигур пригодится разница:

- `fmt.Println("*")` — печатает и **переводит строку**;
- `fmt.Print("*")` — печатает и **остаётся на той же строке**;
- `fmt.Println()` без аргументов — просто перевод строки.

Стандартный паттерн «строка за строкой»: внутренний цикл печатает символы через `Print`, после него — голый `Println()`:

```go
// Квадрат 3×3 из решёток
for i := 0; i < 3; i++ {
    for j := 0; j < 3; j++ {
        fmt.Print("#")
    }
    fmt.Println() // строка собрана — переводим каретку
}
// ###
// ###
// ###
```

## Фигуры: когда внутренний цикл зависит от внешнего

Самое интересное начинается, когда границы внутреннего цикла зависят от счётчика внешнего:

```go
// Треугольник высоты 4
for i := 1; i <= 4; i++ {
    for j := 0; j < i; j++ { // на i-й строке — i звёздочек
        fmt.Print("*")
    }
    fmt.Println()
}
// *
// **
// ***
// ****
```

А вот таблица умножения — числа вместо звёздочек:

```go
for i := 1; i <= 3; i++ {
    for j := 1; j <= 3; j++ {
        fmt.Print(i*j, " ")
    }
    fmt.Println()
}
// 1 2 3
// 2 4 6
// 3 6 9
```

Шахматный узор — внутри вложенных циклов отлично живёт `if`. Клетка `(i, j)` красится по чётности суммы координат:

```go
n := 4
for i := 0; i < n; i++ {
    for j := 0; j < n; j++ {
        if (i+j)%2 == 0 {
            fmt.Print("#")
        } else {
            fmt.Print(".")
        }
    }
    fmt.Println()
}
// #.#.
// .#.#
// #.#.
// .#.#
```

## Перебор пар

Вторая суперсила вложенных циклов — перебрать **все пары** значений. Например, разложить число 91 на два множителя:

```go
for a := 2; a <= 91; a++ {
    for b := a; b <= 91; b++ { // b стартует с a: пара (7, 13) = (13, 7), хватит одной
        if a*b == 91 {
            fmt.Println(a, "×", b)
        }
    }
}
// 7 × 13
```

Обратите внимание на `b := a` — так каждая пара рассматривается один раз, без зеркальных дублей.

## break во вложенных циклах: нужна метка

Помните: `break` прерывает только **ближайший** цикл. В примере выше после находки внутренний цикл можно прервать, но внешний продолжит перебирать `a` дальше — впустую. Хочется выпрыгнуть из обоих сразу? Для этого есть метки (*labels*):

```go
outer:
for a := 2; a <= 91; a++ {
    for b := a; b <= 91; b++ {
        if a*b == 91 {
            fmt.Println(a, "×", b)
            break outer // выходим из ОБОИХ циклов разом
        }
    }
}
```

Метка — это имя с двоеточием (`outer:`) прямо перед циклом. `break outer` прерывает помеченный цикл, каким бы глубоким ни было место вызова. Существует и `continue outer` — перейти к следующей итерации **внешнего** цикла.

> [!NOTE]
> Метки в Go используются редко и только с циклами — это не «goto из страшилок». Если вложенность больше двух и метки начинают путать, обычно это знак, что кусок кода пора вынести в функцию.

## Вложенный цикл + аккумулятор

Аккумуляторы из уровня про `for` отлично работают и здесь — главное решить, ГДЕ обнулять. Сравните:

```go
// Сумма всей таблицы умножения 3×3
total := 0                       // обнулили один раз — копим всё
for i := 1; i <= 3; i++ {
    for j := 1; j <= 3; j++ {
        total += i * j
    }
}
fmt.Println(total) // 36

// Сумма каждой СТРОКИ таблицы отдельно
for i := 1; i <= 3; i++ {
    rowSum := 0                  // обнуляем на каждой строке заново
    for j := 1; j <= 3; j++ {
        rowSum += i * j
    }
    fmt.Println(rowSum)
}
// 6
// 12
// 18
```

Аккумулятор до внешнего цикла — итог за всё; внутри внешнего (но до внутреннего) — итог за одну строку. Перепутаете — получите либо нарастающую кашу, либо вечные нули.

## Цена вопроса: O(n²) на пальцах

Вложенный цикл — это умножение итераций. Два цикла по `n` — `n × n = n²` операций. Программисты говорят: квадратичная сложность (*quadratic complexity*), записывают O(n²).

| n | Один цикл (n шагов) | Вложенный (n² шагов) |
|---|---|---|
| 10 | 10 | 100 |
| 1 000 | 1 000 | 1 000 000 |
| 1 000 000 | мгновенно | 1 000 000 000 000 — минуты и часы! |

Пока n маленькое — никто не заметит. Но «перебор всех пар» на миллионе значений — уже триллион операций. Вложенный цикл — не зло, а инструмент: для таблиц и фигур он идеален, а вот для поиска в больших данных часто существует путь в один проход — на уровнях про слайсы и карты вы такие пути увидите. Полезная привычка: увидели цикл в цикле — прикиньте произведение итераций.

## Типичные ошибки новичка

| Ошибка | Симптом | Как чинить |
|---|---|---|
| один счётчик на оба цикла (`i` внутри и снаружи) | цикл ведёт себя дико или бесконечен | внутреннему циклу — своя переменная `j` |
| `fmt.Println("*")` вместо `Print` во внутреннем цикле | каждая звёздочка на своей строке | `Print` внутри, `Println()` после внутреннего цикла |
| забыт `fmt.Println()` после внутреннего цикла | вся фигура в одну строку | перевод строки — сразу после сборки строки |
| `break` в надежде выйти из обоих циклов | внешний цикл продолжает крутиться | метка: `outer:` + `break outer` |

## Запомнить

- Внутренний цикл прокручивается целиком на каждом шаге внешнего: итераций — произведение.
- Паттерн фигур: `Print` в внутреннем цикле, голый `Println()` после него.
- Граница внутреннего цикла может зависеть от внешнего счётчика (`j < i`) — так рисуют треугольники.
- Все пары без повторов: `for j := i + 1; ...`.
- Выход из нескольких циклов сразу: метка `outer:` перед внешним + `break outer`.
- Два вложенных цикла по n — это O(n²): на больших данных подумайте, нельзя ли обойтись картой или одним проходом.

Вторая задача: бригада суммирует поток — а вы решаете, как собрать общий итог.

Реализуйте функцию:

```go
func SumPool(jobs <-chan int, workers int) int
```

На вход приходит канал значений (он уже наполнен и **закрыт** отправителем — range завершится сам). Ровно `workers` горутин-воркеров разбирают значения из канала; функция возвращает сумму всех значений.

Пример работы:

```go
jobs := make(chan int, 5)
for _, v := range []int{1, 2, 3, 4, 5} {
	jobs <- v
}
close(jobs)

SumPool(jobs, 3) // 15
```

Как собрать итог — выбор ваш, оба способа из урока годятся:

- общий счётчик под `sync.Mutex` (уровень про гонки);
- локальная сумма в каждом воркере + канал результатов, который читает главная горутина.

Чего делать нельзя: писать в общую переменную без защиты — сумма начнёт «терять» слагаемые, и тесты это заметят.

Не меняйте имя и сигнатуру функции.

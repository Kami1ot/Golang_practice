Основная задача: соберите настоящий пул воркеров — фиксированная бригада, очередь задач, результаты по местам.

Реализуйте функцию:

```go
func Process(nums []int, workers int, f func(int) int) []int
```

Она применяет `f` к каждому элементу и возвращает результаты **в исходном порядке**: `res[i] == f(nums[i])`. Требования:

- работу выполняют ровно `workers` горутин-воркеров (не горутина-на-элемент!);
- задачи воркеры берут из общего канала — удобнее всего слать по нему **индексы**;
- каждый воркер пишет результат в свой слот `res[i]` — мьютекс не нужен;
- возврат — после завершения всех воркеров.

Пример работы:

```go
double := func(n int) int { return n * 2 }

Process([]int{1, 2, 3, 4, 5}, 2, double) // [2, 4, 6, 8, 10]
Process([]int{7}, 10, double)            // [14] — лишние воркеры без работы
Process(nil, 3, double)                  // []
```

`workers` всегда ≥ 1, но может быть и больше числа задач — это законно. Тесты проверяют корректность, порядок и то, что одновременно работает не больше `workers` горутин.

Не меняйте имя и сигнатуру функции.

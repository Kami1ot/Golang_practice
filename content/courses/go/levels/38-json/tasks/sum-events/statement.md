Задача со звёздочкой: журнал событий в формате NDJSON — по JSON-объекту на строку.

Реализуйте функцию:

```go
func SumEvents(r io.Reader) (map[string]int, error)
```

Из `r` приходит поток событий вида `{"kind":"click","n":2}` — поле `kind` (строка) и поле `n` (целое). Прочитайте их декодером **до конца потока** и верните карту «kind → сумма всех n этого вида»:

```go
data := `{"kind":"click","n":2}
{"kind":"view","n":1}
{"kind":"click","n":3}`

SumEvents(strings.NewReader(data))
// map[click:5 view:1], nil
```

Правила:

- читать через `json.NewDecoder(r)` и цикл с `dec.More()` — ровно как в уроке; никаких построчных чтений и `ReadAll`;
- любое событие не разобралось — немедленно вернуть эту ошибку (вторым значением), карту в этом случае не проверяем;
- пустой поток — не ошибка: вернуть карту без событий (пустую) и `nil`;
- `n` может быть отрицательным — обычная арифметика;
- события в потоке могут быть отформатированы отступами и переносами — декодеру всё равно.

Не меняйте имя и сигнатуру функции; структура `Event` в заготовке уже с тегами.

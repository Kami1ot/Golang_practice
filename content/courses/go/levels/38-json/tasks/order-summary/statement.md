Разминка: на стандартный ввод приходит JSON-заказ с вложенным списком позиций:

```json
{"customer":"Анна","items":[{"name":"чай","price":120,"qty":2},{"name":"мёд","price":180,"qty":1}]}
```

`price` — цена за штуку, `qty` — количество штук. Прочитайте заказ декодером и выведите одну строку-сводку строго в таком формате:

```
<имя>: позиций <N>, на сумму <X> руб.
```

где `N` — число позиций в заказе (элементов `items`), а `X` — общая стоимость: сумма `price * qty` по всем позициям.

Пример:

```
Ввод:  {"customer":"Анна","items":[{"name":"чай","price":120,"qty":2},{"name":"мёд","price":180,"qty":1}]}
Вывод: Анна: позиций 2, на сумму 420 руб.
```

Чай: 120 × 2 = 240, мёд: 180 × 1 = 180, итого 420. Позиций две — «чай» и «мёд» (количество штук на счётчик позиций не влияет).

Учтите: JSON может прийти отформатированным — с переносами строк и отступами (декодеру это безразлично), а список `items` может оказаться пустым — тогда позиций 0 и сумма 0.

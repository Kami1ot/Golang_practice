Разминка: почините счётчик из урока — раз и навсегда.

Дан тип (менять объявление нельзя):

```go
type SafeCounter struct {
	mu sync.Mutex
	n  int
}
```

Реализуйте два метода:

```go
func (c *SafeCounter) Inc()       // увеличить на 1
func (c *SafeCounter) Value() int // текущее значение
```

Оба должны быть безопасны при вызове из многих горутин одновременно: критические секции — под замком `c.mu`.

Пример работы:

```go
c := SafeCounter{}
// ...500 горутин зовут c.Inc()...
c.Value() // ровно 500, при каждом запуске
```

Не поддавайтесь искушению оставить `Value` без замка «это же только чтение»: чтение одновременно с записью — тоже гонка. Тесты гоняют сотни горутин и проверяют точность счёта.

Не меняйте объявление типа и сигнатуры методов.

Основная задача: турнирная таблица, в которую очки прилетают из многих горутин сразу.

Дан тип (менять объявление нельзя):

```go
type Register struct {
	mu     sync.Mutex
	scores map[string]int
}
```

Реализуйте:

```go
func NewRegister() *Register                    // создаёт готовый к работе реестр
func (r *Register) Add(name string, points int) // добавить игроку очки
func (r *Register) Total(name string) int       // сумма очков игрока (0, если не играл)
```

Пример работы:

```go
r := NewRegister()
r.Add("Аня", 10)
r.Add("Аня", 5)
r.Total("Аня")  // 15
r.Total("Юра")  // 0 — не играл
```

Два подводных камня:

1. Карту нужно создать в `NewRegister` — запись в nil-карту паникует (уровень про panic это обещал).
2. Go паникует и на конкурентной записи в карту без замка: `concurrent map writes`. Оба метода — под мьютексом.

Тесты бомбардируют реестр из сотен горутин и сверяют суммы до очка.

Не меняйте объявление типа и сигнатуры.

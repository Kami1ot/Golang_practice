Задача со звёздочкой: параллельная агрегация — каждый работает над своим куском, итог собирается под замком.

Реализуйте функцию:

```go
func MaxParallel(rows [][]int) int
```

Она находит максимальный элемент всей матрицы:

- максимум **каждой строки** ищет отдельная горутина;
- глобальный максимум обновляется под мьютексом;
- функция возвращается после завершения всех горутин;
- пустая матрица (`len(rows) == 0`) — верните `0`; пустых строк во входе не бывает.

Пример работы:

```go
MaxParallel([][]int{
	{3, 1, 4},
	{1, 5, 9},
	{2, 6, 5},
}) // 9

MaxParallel([][]int{{-7, -3}, {-5, -10}}) // -3 (!)
```

Второй пример — намёк на классическую ловушку: если начать глобальный максимум с нуля, матрица из отрицательных чисел «выиграет» у нуля и ответ будет неверным. Подумайте, с чего начинать.

И держите критическую секцию маленькой: под замком — только сравнение с лидером, а не весь поиск.

Не меняйте имя и сигнатуру функции.

Основная задача: посчитайте суммарную площадь набора фигур, не зная их конкретных типов.

Типы `Shape`, `Rect` и `Circle` уже готовы (методы реализованы — менять их не нужно). Реализуйте функцию:

```go
func TotalArea(shapes []Shape) float64
```

Она возвращает сумму площадей всех фигур слайса. Для пустого (и nil) слайса — `0`.

Пример работы:

```go
shapes := []Shape{
	Rect{W: 3, H: 4},   // 12
	Rect{W: 1, H: 2},   // 2
}
TotalArea(shapes)       // 14
TotalArea(nil)          // 0
```

В слайсе могут быть вперемешку прямоугольники и круги — функция не должна их различать: просто спрашивайте площадь через интерфейс.

Не меняйте имя и сигнатуру функции, объявления типов и их методы.

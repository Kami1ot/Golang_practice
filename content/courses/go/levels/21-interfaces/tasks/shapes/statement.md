Разминка: научите фигуры выполнять контракт. Дан интерфейс и два типа:

```go
type Shape interface {
	Area() float64
}

type Rect struct {
	W, H float64
}

type Circle struct {
	R float64
}
```

Реализуйте методы так, чтобы ОБА типа удовлетворяли интерфейсу `Shape`:

- `(r Rect) Area() float64` — площадь прямоугольника: произведение сторон;
- `(c Circle) Area() float64` — площадь круга: π·R² (используйте `math.Pi`).

Пример работы:

```go
var s Shape = Rect{W: 3, H: 4}
s.Area()                 // 12
s = Circle{R: 1}
s.Area()                 // 3.141592653589793
```

Обратите внимание: никакого `implements` писать не нужно — как только методы готовы, типы реализуют `Shape` автоматически. Тесты проверяют и значения площадей, и сам факт реализации интерфейса.

Не меняйте объявления интерфейса, типов и сигнатуры методов.

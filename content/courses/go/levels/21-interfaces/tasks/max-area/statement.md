Задача со звёздочкой: найдите фигуру-рекордсмена.

Типы `Shape`, `Rect` и `Circle` уже готовы. Реализуйте функцию:

```go
func MaxArea(shapes []Shape) (Shape, bool)
```

Она возвращает фигуру с наибольшей площадью и `true`. Особые случаи:

- слайс пуст (или nil) — верните `nil, false`;
- несколько фигур с одинаковой максимальной площадью — верните **первую** из них.

Пример работы:

```go
shapes := []Shape{
	Rect{W: 1, H: 1},    // 1
	Circle{R: 2},        // ≈12.57
	Rect{W: 3, H: 4},    // 12
}
s, ok := MaxArea(shapes) // Circle{R: 2}, true
MaxArea(nil)             // nil, false
```

Обратите внимание: функция возвращает именно `Shape` — интерфейсное значение можно хранить в переменной и возвращать из функции, как любое другое.

Не меняйте имя и сигнатуру функции, объявления типов и их методы.

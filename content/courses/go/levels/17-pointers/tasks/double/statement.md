Ваша первая функция-модификатор. Реализуйте `Double(n *int)`, которая **удваивает** число по указателю: после вызова в переменной, чей адрес передали, лежит вдвое большее значение.

```go
x := 21
Double(&x)
fmt.Println(x) // 42

Double(&x)
fmt.Println(x) // 84 — каждый вызов удваивает ещё раз
```

Требования:

- функция ничего не возвращает — результат появляется прямо в переменной, чей адрес передан;
- ноль и отрицательные числа тоже удваиваются (математике всё равно);
- не меняйте имя и сигнатуру функции — тесты ищут именно `Double(n *int)`.

В заготовке уже объявлена структура точки на плоскости:

```go
type Point struct {
	X int
	Y int
}
```

Реализуйте две функции, меняющие точку по указателю:

1. `Move(p *Point, dx, dy int)` — сдвигает точку: прибавляет `dx` к `X` и `dy` к `Y`. Смещения могут быть отрицательными.
2. `Reset(p *Point)` — возвращает точку в начало координат: обнуляет обе координаты.

```go
pt := Point{X: 1, Y: 2}
Move(&pt, 3, 4)  // pt стала {4, 6}
Move(&pt, -1, 0) // pt стала {3, 6} — сдвиги накапливаются
Reset(&pt)       // pt стала {0, 0}
```

Требования:

- каждый вызов `Move` работает с текущими координатами — сдвиги накапливаются;
- не меняйте объявление типа `Point`, имена и сигнатуры функций — тесты используют именно их.

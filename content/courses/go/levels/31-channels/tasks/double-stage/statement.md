Задача со звёздочкой: постройте стадию конвейера (*pipeline*) — кирпичик, из которых собирают потоковую обработку данных.

Реализуйте функцию:

```go
func DoubleAll(in <-chan int) <-chan int
```

Она сразу возвращает выходной канал, а горутина перекачивает значения: читает из `in`, удваивает, отправляет в выход. Когда вход закрывается и опустошается — закрывает выход.

Пример работы:

```go
// Squares — генератор из прошлой задачи
for v := range DoubleAll(Squares(3)) {
	fmt.Println(v)
}
// 2
// 8
// 18
```

Требования:

- порядок сохраняется (канал — очередь FIFO);
- выходной канал закрывается после исчерпания входного — стадии можно сцеплять;
- пустой (сразу закрытый) вход — пустой закрытый выход.

Красота паттерна: `DoubleAll(DoubleAll(Squares(3)))` работает без единой правки — выход одной стадии подходит на вход другой. Тесты проверяют и одиночную стадию, и такую цепочку.

Не меняйте имя и сигнатуру функции.

Разминка: верните результат из горутины — так, как это делают в настоящем Go.

Реализуйте функцию:

```go
func SumAsync(a, b int) <-chan int
```

Она **сразу** возвращает канал, а сумму `a + b` считает горутина и отправляет её в этот канал.

Пример работы:

```go
ch := SumAsync(2, 3) // вернулась мгновенно
// ...можно заняться другими делами...
fmt.Println(<-ch)    // 5 — забираем, когда понадобилось
```

Обратите внимание на тип результата `<-chan int` — вызывающий может только читать из канала: по сигнатуре видно, что это источник данных. Внутри функции создавайте обычный `chan int` — Go сам приведёт его к направленному.

Тесты проверяют, что функция возвращается сразу (не блокируясь), а значение приходит по каналу.

Не меняйте имя и сигнатуру функции.

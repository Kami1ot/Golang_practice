Основная задача: постройте генератор — функцию, которая отдаёт поток значений через канал.

Реализуйте функцию:

```go
func Squares(n int) <-chan int
```

Она сразу возвращает канал, в который горутина отправляет квадраты чисел от 1 до n — по порядку: `1, 4, 9, …, n²` — и **закрывает канал** после последнего.

Пример работы:

```go
for v := range Squares(4) {
	fmt.Println(v)
}
// 1
// 4
// 9
// 16
```

Требования:

- значения идут по возрастанию, от `1²` до `n²`;
- после последнего значения канал закрывается — иначе range у потребителя зависнет навсегда;
- `Squares(0)` — корректный случай: канал без единого значения, сразу закрытый.

Тесты перебирают канал range-циклом и проверяют, что он действительно закрывается.

Не меняйте имя и сигнатуру функции.

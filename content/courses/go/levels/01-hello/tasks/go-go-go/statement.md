Напечатайте кричалку болельщиков Go — ровно две строки:

```
Go!Go!Go!
Вперёд!
```

Условие со звёздочкой: первую строку соберите из **трёх отдельных вызовов** `fmt.Print("Go!")` — они печатают в одну строку без пробелов, потому что `Print` не добавляет перевод строки.

Подумайте, как после этого перейти на новую строку (подсказка: `fmt.Println()` можно вызвать вовсе без аргументов).

Задача **необязательная**, но отлично закрепляет разницу между `Print` и `Println`.

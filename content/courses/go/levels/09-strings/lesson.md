# Строки и руны — текст под микроскопом

Строками вы пользуетесь с первого уровня, но пока — как чёрным ящиком. Пора вскрыть: внутри у строки байты, снаружи — символы, а между ними — кодировка UTF-8. Для русскоязычных программ эта разница не факультатив, а техника безопасности.

## Строка — неизменяемые байты

Строка (*string*) в Go — это последовательность **байтов** (*bytes*), и она **неизменяема** (*immutable*):

```go
s := "город"
s = "море"      // можно: переменная теперь указывает на другую строку
s[0] = 'м'      // НЕЛЬЗЯ: cannot assign to s[0] — ошибка компиляции
```

Заменить строку целиком — пожалуйста; поменять байт внутри — никогда. Все «изменяющие» операции на самом деле строят новую строку.

## len считает байты, а не буквы

Строки хранятся в кодировке UTF-8: латинская буква занимает 1 байт, русская — 2, иероглиф — 3, эмодзи — 4.

```go
fmt.Println(len("go"))      // 2 — две буквы, два байта
fmt.Println(len("го"))      // 4 — две буквы, четыре байта!
fmt.Println(len("го!"))     // 5 — г(2) + о(2) + !(1)
```

> [!WARNING]
> `len(s)` — это **байты**. Для русского текста «длина в буквах» через `len` завышена ровно вдвое — источник бесконечных багов. Хотите считать буквы — считайте руны (ниже).

Индексация `s[i]` тоже байтовая: `"го"[0]` вернёт не букву `г`, а первый из двух её байтов — число 208. Для текстов с не-латиницей прямую индексацию лучше не использовать вовсе.

## Руны — честные символы

Руна (*rune*) — это один символ Юникода (технически: числовой код символа, тип `rune` = `int32`). Строку можно развернуть в слайс рун:

```go
r := []rune("го!")
fmt.Println(len(r))         // 3 — вот теперь честные символы
fmt.Println(string(r[0]))   // г — руну обратно в строку через string()
```

Таблица-шпаргалка:

| Выражение | Что считает | `"го!"` |
|---|---|---|
| `len(s)` | байты | 5 |
| `len([]rune(s))` | символы (руны) | 3 |

Слайс рун — изменяемый: через него делают «редактирование» строки:

```go
r := []rune("кот")
r[0] = 'б'
fmt.Println(string(r))      // бот
```

## range по строке — идёт по рунам

`range` знает про UTF-8 и выдаёт руны, а не байты. Первая переменная — **байтовая** позиция начала руны (поэтому с кириллицей она прыгает через 2):

```go
for i, r := range "го!" {
    fmt.Println(i, string(r))
}
// 0 г
// 2 о      ← позиция 2, а не 1: буква «г» заняла байты 0 и 1
// 4 !
```

Просто перебрать символы — игнорируйте индекс:

```go
count := 0
for range "привет" {
    count++
}
fmt.Println(count)          // 6
```

## Склейка строк

Оператор `+` соединяет строки, `+=` дописывает:

```go
name := "Гофер"
greet := "Привет, " + name + "!"
fmt.Println(greet)          // Привет, Гофер!
```

> [!NOTE]
> Каждая склейка создаёт новую строку (старые неизменяемы!). Пара склеек — нормально; склейка в цикле на тысячи итераций — медленно. Для таких случаев в Go есть `strings.Builder` — копилка, из которой строка забирается один раз в конце. Пока просто запомните имя: понадобится — найдёте в документации.

## Пакет strings — готовые инструменты

Импортируйте `"strings"` — и почти любая бытовая операция уже написана:

```go
import (
    "fmt"
    "strings"
)

func main() {
    s := "Go любит гоферов"
    fmt.Println(strings.Contains(s, "любит"))       // true — есть ли подстрока
    fmt.Println(strings.ToUpper("go"))              // GO
    fmt.Println(strings.ToLower("ГОФЕР"))           // гофер
    fmt.Println(strings.ReplaceAll(s, "о", "0"))    // Go любит г0фер0в
    // заметьте: «o» в Go — латинская, а заменяли мы кириллическую «о»
    fmt.Println(strings.Repeat("ха", 3))            // хахаха
    fmt.Println(strings.TrimSpace("  go  "))        // go — срезал пробелы по краям
}
```

Разбор и сборка списков:

```go
csv := "красный,зелёный,синий"
parts := strings.Split(csv, ",")      // слайс строк: [красный зелёный синий]
fmt.Println(len(parts))               // 3

words := strings.Fields("  go   is  fun ") // разбить по ЛЮБЫМ пробелам
fmt.Println(words)                    // [go is fun] — пустых элементов не бывает

joined := strings.Join(parts, " и ")
fmt.Println(joined)                   // красный и зелёный и синий
```

Шпаргалка:

| Функция | Что делает |
|---|---|
| `Contains(s, sub)` | есть ли подстрока → bool |
| `Split(s, sep)` | разрезать по разделителю → []string |
| `Fields(s)` | разрезать по пробелам, пустое выкинуть → []string |
| `Join(parts, sep)` | склеить слайс строк через разделитель |
| `ToUpper / ToLower` | верхний/нижний регистр (кириллицу понимает) |
| `ReplaceAll(s, old, new)` | заменить все вхождения |
| `TrimSpace(s)` | убрать пробелы и переводы строк по краям |
| `Repeat(s, n)` | повторить строку n раз |

## strconv — строки ↔ числа

Пакет `strconv` конвертирует строки в числа и обратно:

```go
import "strconv"

n, err := strconv.Atoi("42")   // строка → число; Atoi = ASCII to integer
if err != nil {
    fmt.Println("это не число!")
}
fmt.Println(n + 1)             // 43

s := strconv.Itoa(7)           // число → строка
fmt.Println(s + "7")           // 77 — это склейка строк, не сложение!
```

`Atoi` возвращает **два** значения — результат и ошибку. Знакомо? Это та же идея, что ok-идиома у карт: второе значение отвечает «а получилось ли». `err == nil` — получилось; подробно про ошибки — в следующей секции курса.

## Сравнение строк

Строки сравниваются операторами `==`, `!=`, `<`, `>` — побайтово:

```go
fmt.Println("го" == "го")     // true
fmt.Println("Го" == "го")     // false — регистр важен!
```

Сравнение без учёта регистра — привести обе стороны к одному регистру: `strings.ToLower(a) == strings.ToLower(b)`.

## Типичные ошибки новичка

| Код | Что случится | Как чинить |
|---|---|---|
| `s[0] = 'а'` | `cannot assign to s[0]` — строки неизменяемы | `r := []rune(s)`, менять руны, обратно `string(r)` |
| `len("привет")` как «число букв» | получите 12 вместо 6 | `len([]rune(s))` |
| `fmt.Println(s[0])` для кириллицы | напечатается байт-число (208), не буква | `string([]rune(s)[0])` или range |
| `"7" + "7"` в надежде на 14 | получится строка `"77"` | сначала `strconv.Atoi`, потом сложение |
| `strconv.Atoi(s)` без проверки `err` | мусор на входе даст 0 без предупреждения | проверять `if err != nil` |

## Запомнить

- Строка — неизменяемые байты в UTF-8; русская буква = 2 байта.
- `len(s)` — байты; `len([]rune(s))` — символы. Для кириллицы это разные числа!
- `range` по строке идёт по рунам, индекс — байтовая позиция (прыгает).
- «Изменить строку» = построить новую: `[]rune` → правка → `string()`.
- `strings`: Contains, Split, Fields, Join, ToUpper/ToLower, ReplaceAll, TrimSpace, Repeat.
- `strconv.Atoi(s)` → (число, ошибка); `strconv.Itoa(n)` → строка.
- Много склеек в цикле — вспомнить про `strings.Builder`.

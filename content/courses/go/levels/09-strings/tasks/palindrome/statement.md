Реализуйте функцию `IsPalindrome(s string) bool`, которая проверяет, является ли строка палиндромом (*palindrome*) — читается ли она одинаково слева направо и справа налево.

```go
IsPalindrome("шалаш")  // true
IsPalindrome("го")     // false
IsPalindrome("")       // true — пустая строка палиндром
IsPalindrome("я")      // true — один символ тоже
```

Требования:

- регистр учитывается: `"Аня"` — не палиндром (`А` ≠ `я`);
- строка может содержать **кириллицу** — значит, сравнивать байты нельзя, только руны;
- не меняйте имя и сигнатуру функции — тесты ищут именно `IsPalindrome(s string) bool`.

> Проверка на байтах (`s[i] == s[len(s)-1-i]`) случайно пройдёт на латинице и развалится на русском слове — тесты это ловят.

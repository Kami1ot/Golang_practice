Прочитайте `n` (1 ≤ n ≤ 100), затем `n` слов (каждое читается через `fmt.Scan`). Выведите **самое длинное** слово, где длина считается в **символах** (рунах), а не в байтах. Если самых длинных несколько — выведите **первое** из них.

Пример:

```
Ввод:  3
       go язык fun
Вывод: язык
```

`язык` — 4 символа, `fun` — 3, `go` — 2.

Задача **со звёздочкой** и с ловушкой из урока: слова могут быть и русскими, и английскими. Программа, меряющая длину байтами через `len(w)`, посчитает «яяя» (6 байт) длиннее «abcd» (4 байта) — и провалит скрытый тест.

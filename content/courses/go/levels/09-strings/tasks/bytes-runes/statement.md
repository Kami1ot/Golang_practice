Разминка-измеритель. Прочитайте одно слово (без пробелов) и выведите через пробел два числа:

1. длину слова в **байтах**;
2. длину слова в **символах** (рунах).

Пример:

```
Ввод:  go
Вывод: 2 2
```

Для латиницы числа совпадают. А вот для русских слов — нет: проверьте на слове «привет» у себя в голове, прежде чем сдавать.

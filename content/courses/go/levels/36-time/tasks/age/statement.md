Задача со звёздочкой: классика собеседований — возраст в полных годах. Звучит тривиально, а наивные решения стабильно ошибаются на единицу.

Реализуйте функцию:

```go
func Age(birth, today time.Time) int
```

Она возвращает число **полных лет** между датой рождения `birth` и днём `today`:

- если день рождения в этом году уже был (или он **сегодня**) — год засчитан;
- если ещё не наступил — не засчитан.

Пример работы:

```go
birth := time.Date(2000, time.September, 1, 0, 0, 0, 0, time.UTC)

Age(birth, time.Date(2026, time.July, 17, 0, 0, 0, 0, time.UTC))      // 25 — сентябрь ещё впереди
Age(birth, time.Date(2026, time.September, 1, 0, 0, 0, 0, time.UTC))  // 26 — с днём рождения!
```

Разница `today.Year() - birth.Year()` — только заготовка ответа: она не знает, был ли уже день рождения. Не сравнивайте месяцы и дни вручную по отдельности — в уроке есть приём с `AddDate` и `After`, который закрывает все случаи одной проверкой (даже рождённых 29 февраля: их «день рождения» в невисокосный год нормализуется на 1 марта — тесты так и ожидают).

Обе даты приходят в UTC с нулевым временем суток; `today` не бывает раньше `birth`.

Не меняйте имя и сигнатуру функции.

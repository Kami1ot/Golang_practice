Прочитайте три целых числа и выведите наибольшее из них.

**Ввод:** три целых числа через пробел.
**Вывод:** одно число — максимум.

Пример:

```
Ввод:  3 7 5
Вывод: 7
```

Числа могут быть отрицательными и могут совпадать (если наибольшее встречается дважды — выведите его один раз, оно же всё равно одно значение).

Красивое решение — не гора вложенных `if`, а переменная-«кандидат», которую вы улучшаете по мере проверки. Подсказки помогут, если застрянете.

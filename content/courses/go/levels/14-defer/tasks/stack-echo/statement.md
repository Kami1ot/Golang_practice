Разминка, в которой стопка defer видна невооружённым глазом.

Первая строка ввода — число `n` (n ≥ 1). Далее `n` слов, по одному на строке. Для каждого прочитанного слова:

1. **сразу** напечатайте строку `-> слово`;
2. тут же **отложите** через `defer` печать строки `<- слово`.

В итоге программа выведет `n` строк со стрелкой вправо в прямом порядке, а затем `n` строк со стрелкой влево — в обратном. Разворачивать ничего не нужно: стопка отложенных вызовов сделает это сама.

Пример:

```
Ввод:  3
       go
       is
       fun
Вывод: -> go
       -> is
       -> fun
       <- fun
       <- is
       <- go
```

Между стрелкой и словом — один пробел (`fmt.Println("->", w)` печатает именно так).

Игровой сервер начисляет очки так: базовое значение удваивается, а в самом конце — уже на выходе из функции — добавляется бонус 10.

Реализуйте функцию `FinalScore(base int) (score int)`:

- тело функции записывает в `score` удвоенный `base`;
- бонус `+10` добавляет **отложенное замыкание**: `defer` с анонимной функцией, которая меняет именованный результат `score` уже после `return`.

```go
FinalScore(5)   // 20: 5*2 = 10, затем defer добавил 10
FinalScore(0)   // 10: база нулевая, но бонус добавляется всегда
FinalScore(-3)  // 4: -3*2 = -6, плюс 10
```

Требования:

- бонус — именно через `defer` + именованный результат (это и есть приём из урока; тест видит только итоговое число, но суть задачи — в способе);
- не меняйте имя и сигнатуру функции — тесты ищут именно `FinalScore(base int) (score int)`.

Разминка: научитесь предлагать, а не навязывать.

Реализуйте функцию:

```go
func TrySend(ch chan int, v int) bool
```

Она **пытается** отправить значение в канал:

- отправка возможна прямо сейчас (в буфере есть место или приёмник уже ждёт) — отправить и вернуть `true`;
- канал не готов принять — **не блокироваться**, вернуть `false`.

Пример работы:

```go
ch := make(chan int, 2)
TrySend(ch, 1) // true — легло в буфер
TrySend(ch, 2) // true — буфер полон, но место было
TrySend(ch, 3) // false — мест нет, значение НЕ отправлено
<-ch           // освободили место
TrySend(ch, 3) // true
```

Так работают сборщики метрик и логов: если очередь захлебнулась, лучше выбросить одно измерение, чем подвесить всю программу. Обычная отправка `ch <- v` здесь не подходит — она заблокируется; нужен `select` с `default`.

Не меняйте имя и сигнатуру функции.

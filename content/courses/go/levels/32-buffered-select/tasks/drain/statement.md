Задача со звёздочкой: соберите всё, что уже накопилось, — и ни секундой дольше.

Реализуйте функцию:

```go
func Drain(ch <-chan int) []int
```

Она забирает из канала все значения, доступные **прямо сейчас**, и возвращает их слайсом в порядке очереди:

- в буфере лежат значения — забрать все до опустошения;
- канал пуст — мгновенно вернуть пустой слайс, **не дожидаясь** новых значений;
- канал закрыт — вернуть то, что оставалось в буфере (и не зациклиться!).

Пример работы:

```go
ch := make(chan int, 5)
ch <- 1
ch <- 2
ch <- 3
Drain(ch) // [1, 2, 3]
Drain(ch) // [] — уже пусто, ждать не стали
```

Подвох — в случае закрытого канала: приём из него всегда «готов», поэтому наивный цикл с `case v := <-ch` начнёт бесконечно собирать нули. Вспомните ok-идиому приёма.

Не меняйте имя и сигнатуру функции.

Основная задача: два зеркала одного сервиса наперегонки отвечают на запрос — берём ответ быстрейшего.

Реализуйте функцию:

```go
func FirstOf(a, b <-chan string) string
```

Она ждёт значение из **любого** из двух каналов и возвращает первое пришедшее. Из какого канала — неважно: кто раньше, тот и выиграл.

Пример работы:

```go
fast := make(chan string, 1)
slow := make(chan string) // молчит

fast <- "ответ зеркала А"
FirstOf(fast, slow) // "ответ зеркала А" — не дожидаясь второго
```

Требования:

- если готов только один канал — вернуть его значение, не дожидаясь второго;
- если не готов ни один — честно ждать первого (без default!);
- каналы равноправны: значение может прийти и из `a`, и из `b`.

Это ровно тот случай, ради которого select придумали: последовательные приёмы `<-a; <-b` застряли бы на молчащем канале.

Не меняйте имя и сигнатуру функции.

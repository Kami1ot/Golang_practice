Основная задача: облачное хранилище должно сообщать не просто «нельзя», а «сколько именно не влезло».

Дан тип (заполните его метод):

```go
type QuotaError struct {
	Used, Limit int
}
```

Реализуйте две вещи:

1. Метод `(e QuotaError) Error() string` — сообщение строго в формате:
   `квота исчерпана: 115 из 100` (числа — из полей).
2. Функцию `Upload(used, limit, size int) error`:
   - если после загрузки объём превысит лимит (`used+size > limit`) — верните
     `QuotaError`, где `Used` — объём ПОСЛЕ загрузки, `Limit` — лимит;
   - иначе — `nil` (ровно в лимит — можно!).

Пример работы:

```go
Upload(50, 100, 30)   // nil — 80 из 100
Upload(50, 100, 50)   // nil — ровно в лимит
err := Upload(90, 100, 25)
err.Error()           // "квота исчерпана: 115 из 100"

var qe QuotaError
errors.As(err, &qe)   // true
qe.Used - qe.Limit    // 15 — вызывающий знает, сколько не влезло
```

Смысл задачи: данные о переборе едут наверх в полях структуры, а не в тексте — вызывающий достанет их `errors.As` и посчитает, что показать пользователю.

Не меняйте объявление типа, имена и сигнатуры.

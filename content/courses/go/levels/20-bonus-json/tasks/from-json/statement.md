На вход подаётся JSON-объект книги вида `{"title":"...","pages":N}`. Заголовок может содержать пробелы, а сам JSON — переносы строк, поэтому читайте его рецептом из урока: `json.NewDecoder(os.Stdin)` и `Decode` в структуру `Book` с полями `Title string` и `Pages int` (теги уже в заготовке).

Выведите две строки: заголовок книги и число страниц.

Пример:

```
Ввод:  {"title":"Go для всех","pages":320}
Вывод: Go для всех
       320
```

Помните из урока: отсутствующее в JSON поле — не ошибка, а лишнее — не помеха.

Разминка-сериализатор. Прочитайте через `fmt.Scan` имя игрока (одно слово) и его счёт (целое число). Положите их в структуру `Player` с полями `Name string` и `Score int` и тегами `json:"name"` и `json:"score"`, сериализуйте её `json.Marshal` и напечатайте одну строку JSON.

Пример:

```
Ввод:  gopher 42
Вывод: {"name":"gopher","score":42}
```

В заготовке структура уже объявлена, но теги в ней потерялись — восстановите их точно по образцу, иначе поля уедут в JSON с большой буквы.

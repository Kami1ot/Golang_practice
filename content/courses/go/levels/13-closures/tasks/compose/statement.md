Реализуйте функцию `Compose(f, g func(int) int) func(int) int`, которая возвращает композицию (*composition*) — функцию `h`, такую что:

```
h(x) == f(g(x))
```

Порядок — как в математике (f∘g, «f после g»): **сначала** применяется `g`, **потом** `f` к её результату.

```go
inc := func(x int) int { return x + 1 }
double := func(x int) int { return x * 2 }

h := Compose(inc, double)
h(3) // 7: сначала double (3·2 = 6), потом inc (6+1 = 7)

h2 := Compose(double, inc)
h2(3) // 8: сначала inc (3+1 = 4), потом double (4·2 = 8)
```

Требования:

- порядок строго `f(g(x))` — тесты подобраны так, что перепутанный порядок не пройдёт;
- возвращённую функцию можно вызывать сколько угодно раз с разными аргументами;
- не меняйте имя и сигнатуру функции — тесты ищут именно `Compose(f, g func(int) int) func(int) int`.

Реализуйте фабрику `MakeCounter() func() int`, которая возвращает функцию-счётчик: первый её вызов возвращает 1, второй — 2, третий — 3 и так далее.

```go
next := MakeCounter()
next() // 1
next() // 2
next() // 3

other := MakeCounter() // новый счётчик — новая память
other() // 1 — начинает со своей единицы
next()  // 4 — а этот продолжает со своего места
```

Требования:

- каждый счётчик, созданный отдельным вызовом `MakeCounter()`, считает **независимо** — тесты создают несколько и проверяют, что они не мешают друг другу;
- не меняйте имя и сигнатуру функции — тесты ищут именно `MakeCounter() func() int`.

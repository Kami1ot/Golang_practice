Разминка с колбэком. Реализуйте функцию `Apply(nums []int, f func(int) int) []int`, которая возвращает **новый** слайс: каждый элемент `nums`, пропущенный через функцию `f`.

```go
Apply([]int{1, 2, 3}, func(x int) int { return x * 2 })   // [2 4 6]
Apply([]int{-2, 0, 5}, func(x int) int { return x * x })  // [4 0 25]
```

Требования:

- исходный слайс `nums` менять **нельзя** — стройте и возвращайте новый (тест это проверяет);
- порядок элементов сохраняется;
- пустой вход — пустой выход;
- не меняйте имя и сигнатуру функции — тесты ищут именно `Apply(nums []int, f func(int) int) []int`.

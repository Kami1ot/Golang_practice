Напишите «инспектора»: он читает слово и целое число, а затем докладывает о каждом — что за значение и какого оно типа.

**Ввод:** слово и целое число через пробел.
**Вывод:** две строки в точном формате:

```
Ввод:  Go 42
Вывод: слово "Go" имеет тип string
       число 42 имеет тип int
```

Требования:

- слово печатается **в двойных кавычках** — используйте подходящий глагол, а не кавычки в тексте формата;
- названия типов (`string`, `int`) не пишите руками — пусть их печатает `Printf` специальным глаголом.

Задача **необязательная**, но `%q` и `%T` — вернейшие друзья отладки, стоит их приручить.

# Бонус: форматированный вывод

`fmt.Println` хорош для быстрого вывода, но у него всё жёстко: пробелы между аргументами, перевод строки в конце. Когда нужен **точный** формат — ценник, таблица, отчёт — на сцену выходит `fmt.Printf` (*print formatted*). Этот бонусный уровень — про тонкий контроль над каждым символом вывода.

## Printf: строка формата и глаголы

Первый аргумент `Printf` — строка формата (*format string*) с плейсхолдерами, которые в Go называют глаголами (*verbs*). Каждый глагол начинается с `%` и подставляет очередной аргумент:

```go
name, age := "Гоша", 25
fmt.Printf("Меня зовут %s, мне %d лет\n", name, age)
// Вывод:
// Меня зовут Гоша, мне 25 лет
```

`%s` съел `name`, `%d` съел `age` — по порядку, слева направо.

> [!WARNING]
> `Printf` **не** добавляет перевод строки автоматически — не забывайте `\n` в конце строки формата. Забытый `\n` — самая частая причина «слипшегося» вывода.

## Таблица глаголов

| Глагол | Для чего | Пример | Вывод |
|---|---|---|---|
| `%d` | целые числа | `fmt.Printf("%d", 42)` | `42` |
| `%s` | строки | `fmt.Printf("%s", "го")` | `го` |
| `%f` | дробные | `fmt.Printf("%f", 3.14)` | `3.140000` |
| `%t` | bool | `fmt.Printf("%t", true)` | `true` |
| `%v` | любое значение «по умолчанию» | `fmt.Printf("%v", 42)` | `42` |
| `%+v` | как `%v`, но структуры — с именами полей | пригодится в уровне про структуры | |
| `%T` | **тип** значения | `fmt.Printf("%T", 3.14)` | `float64` |
| `%q` | строка **в кавычках** | `fmt.Printf("%q", "го")` | `"го"` |
| `%%` | сам знак процента | `fmt.Printf("100%%")` | `100%` |

Пара глаголов заслуживает отдельного слова:

- `%v` (*value*) — универсал: печатает что угодно в формате по умолчанию. Не знаете, какой глагол взять — берите `%v`.
- `%T` (*Type*) — печатает **тип** аргумента. Вместе с `%v` — главные друзья отладки:

```go
x := 3.5
fmt.Printf("значение %v имеет тип %T\n", x, x)
// Вывод:
// значение 3.5 имеет тип float64
```

- `%q` (*quoted*) — печатает строку в двойных кавычках. Незаменим, когда надо увидеть невидимое: пробелы в начале, пустую строку:

```go
s := "го "
fmt.Printf("%s|\n", s)   // го |      (пробел не виден)
fmt.Printf("%q\n", s)    // "го "    (виден!)
```

> [!WARNING]
> Не путайте `%t` и `%T`: строчная — для `bool` (`true`/`false`), заглавная — для типа. Подставите не то — Go не упадёт, а напечатает подсказку прямо в вывод: `fmt.Printf("%d", "го")` даст `%!d(string=го)`. Увидели `%!` в выводе — ищите несовпадение глагола и аргумента.

## Ширина и точность

Между `%` и буквой глагола помещаются модификаторы: `%[ширина].[точность]f`.

**Точность** (*precision*) — число знаков после точки, с округлением:

```go
pi := 3.14159265
fmt.Printf("%.2f\n", pi)   // 3.14
fmt.Printf("%.4f\n", pi)   // 3.1416
fmt.Printf("%.0f\n", pi)   // 3
```

**Ширина** (*width*) — минимальное число символов; не хватает — Go добьёт пробелами слева (выравнивание по правому краю):

```go
fmt.Printf("[%8.2f]\n", 3.14159)  // [    3.14]
fmt.Printf("[%8d]\n", 42)         // [      42]
fmt.Printf("[%8s]\n", "го")       // [      го]
```

Минус перед шириной — выравнивание по **левому** краю:

```go
fmt.Printf("[%-8s]|\n", "го")     // [го      ]|
```

Так строят аккуратные таблицы:

```go
fmt.Printf("%-10s %5d\n", "яблоки", 12)
fmt.Printf("%-10s %5d\n", "груши", 7)
// Вывод:
// яблоки        12
// груши          7
```

## Экранирование: \n, \t, \"

Внутри строк в двойных кавычках работают управляющие последовательности (*escape sequences*):

| Запись | Что означает |
|---|---|
| `\n` | перевод строки |
| `\t` | табуляция |
| `\"` | двойная кавычка внутри строки |
| `\\` | сам обратный слеш |

```go
fmt.Println("первая\nвторая")
// Вывод:
// первая
// вторая

fmt.Println("колонка1\tколонка2")
// Вывод:
// колонка1	колонка2

fmt.Println("она сказала: \"привет\"")
// Вывод:
// она сказала: "привет"
```

## Семейство Print: кто есть кто

| Функция | Перевод строки | Пробелы между аргументами | Формат |
|---|---|---|---|
| `fmt.Print(a, b)` | нет | только между числами | нет |
| `fmt.Println(a, b)` | да | всегда | нет |
| `fmt.Printf(fmt, a, b)` | нет (пишите `\n`) | вы решаете | глаголы |

## Sprintf: формат без печати

Иногда отформатированная строка нужна не на экран, а **в переменную** — для этого есть `fmt.Sprintf`: те же глаголы, но результат возвращается строкой:

```go
label := fmt.Sprintf("%s: %d очков", "Гоша", 99)
fmt.Println(label)
// Вывод:
// Гоша: 99 очков
```

Мнемоника: приставка `S` = *string* — «верни строку вместо печати». У `Print` и `Println` тоже есть S-братья (`Sprint`, `Sprintln`), но `Sprintf` — самый ходовой.

## Типичные ошибки новичка

### 1. Забытый аргумент

```go
fmt.Printf("%s набрал %d очков\n", "Гоша")
```

Компилируется, но в выводе появится маркер:

```
Гоша набрал %!d(MISSING) очков
```

**Как чинить:** число глаголов = число аргументов. `go vet` ловит это автоматически.

### 2. Лишний аргумент

```go
fmt.Printf("итог: %d\n", 42, 99)
```

```
итог: 42
%!(EXTRA int=99)
```

**Как чинить:** то же правило, лишний аргумент убрать.

### 3. Println с \n

```go
fmt.Println("привет\n")
```

Печатает `привет` и **два** перевода строки — один даёт `\n`, второй добавляет сам `Println`. В выводе появляется лишняя пустая строка. **Как чинить:** с `Println` перевод строки не нужен; `\n` — для `Print` и `Printf`.

## Запомнить

- `Printf` подставляет аргументы вместо глаголов: `%d` — целые, `%s` — строки, `%f` — дробные, `%t` — bool.
- `%v` — любое значение по умолчанию, `%T` — тип значения, `%q` — строка в кавычках, `%%` — сам процент.
- `%.2f` — два знака после точки (с округлением); `%8.2f` — ещё и ширина 8; `%-8s` — выравнивание влево.
- `Printf` не переводит строку — заканчивайте формат на `\n`.
- `\n` — новая строка, `\t` — табуляция, `\"` — кавычка в строке.
- `Sprintf` форматирует и **возвращает** строку вместо печати.
- `%!` в выводе — сигнал: глагол не совпал с аргументом или аргументов не хватило.

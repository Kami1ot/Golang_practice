Реализуйте функцию `SumDigits(n int) int`, которая **рекурсивно** считает сумму цифр неотрицательного числа `n`.

```go
SumDigits(0)     // 0
SumDigits(7)     // 7  — однозначное число: сумма цифр равна ему самому
SumDigits(12345) // 15 — это 1+2+3+4+5
```

Требования:

- решение должно быть рекурсивным: базовый случай — однозначное число (`n < 10`), рекурсивный шаг отделяет последнюю цифру;
- `n` неотрицательно, проверять на отрицательные значения не нужно;
- не меняйте имя и сигнатуру функции — тесты ищут именно `SumDigits(n int) int`.

Число разбирается как матрёшка из урока: `%` открывает последнюю цифру, `/` отдаёт всё остальное. Нули внутри числа (например, в 10203) не должны ломать подсчёт.

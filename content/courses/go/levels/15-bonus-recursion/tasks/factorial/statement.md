Разминка. Реализуйте функцию `Factorial(n int) int`, которая **рекурсивно** вычисляет факториал: n! = 1 · 2 · … · n, причём `Factorial(0)` равен 1 по определению.

```go
Factorial(0) // 1
Factorial(1) // 1
Factorial(5) // 120
```

Требования:

- решение должно быть рекурсивным — функция вызывает саму себя, без циклов;
- считайте, что 0 ≤ n ≤ 12 — результат помещается в `int`, о переполнении думать не нужно;
- не меняйте имя и сигнатуру функции — тесты ищут именно `Factorial(n int) int`.

Начните с базового случая, а рекурсивный шаг подскажет формула n! = n · (n−1)!

Задача **со звёздочкой**. Реализуйте функцию `Fib(n int) int`, возвращающую n-е число Фибоначчи:

- `Fib(0)` = 0;
- `Fib(1)` = 1;
- дальше каждое число — сумма двух предыдущих: 0, 1, 1, 2, 3, 5, 8, 13, 21, …

```go
Fib(2)  // 1
Fib(10) // 55
```

Требования:

- решение должно быть рекурсивным — наивная версия из урока подойдёт: в тестах n ≤ 30, она успевает до таймаута;
- обратите внимание: базовых случаев здесь ДВА — рекурсивный шаг опирается на два предыдущих значения;
- не меняйте имя и сигнатуру функции — тесты ищут именно `Fib(n int) int`.

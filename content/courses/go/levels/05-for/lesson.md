# Цикл for — единственный, но всемогущий

До сих пор наши программы выполнялись сверху вниз ровно один раз. Но настоящая сила компьютера — делать одно и то же миллионы раз, не уставая и не жалуясь. За повторение в Go отвечает цикл (*loop*).

В большинстве языков есть целый зоопарк: `while`, `do-while`, `for`, `foreach`… В Go цикл ровно **один** — `for`. Зато он умеет принимать три формы и заменяет их все.

## Форма 1: классический for со счётчиком

```go
for i := 0; i < 5; i++ {
    fmt.Println("итерация", i)
}
// итерация 0
// итерация 1
// итерация 2
// итерация 3
// итерация 4
```

Заголовок цикла состоит из трёх частей, разделённых точкой с запятой:

| Часть | Пример | Когда выполняется |
|---|---|---|
| инициализация (*init*) | `i := 0` | один раз, перед первой итерацией |
| условие (*condition*) | `i < 5` | перед **каждой** итерацией; `false` → выход |
| пост-действие (*post*) | `i++` | после **каждой** итерации |

Переменная `i` — счётчик (*counter*). Она видна только внутри цикла: после `}` обратиться к `i` уже нельзя.

`i++` — отдельный оператор «увеличить на единицу» (*increment*). Есть и `i--` — уменьшить. В Go это именно операторы, а не выражения: написать `x := i++` нельзя.

> [!NOTE]
> Как и у `if`, круглые скобки вокруг заголовка не ставятся, а фигурные скобки обязательны всегда: `for i := 0; i < 5; i++ {` — и никак иначе.

## Форма 2: for-условие (стиль while)

Если инициализация и пост-действие не нужны, оставьте только условие — получится то, что в других языках называют `while`:

```go
n := 32
steps := 0
for n > 1 {
    n = n / 2
    steps++
}
fmt.Println(steps) // 5  (32 → 16 → 8 → 4 → 2 → 1)
```

Цикл крутится, пока условие истинно. Обновлять переменные условия — ваша забота: забудете — цикл никогда не закончится.

## Форма 3: вечный цикл + break

Уберём вообще всё — получим бесконечный цикл (*infinite loop*):

```go
for {
    fmt.Println("вечно...")
}
```

Сам по себе он полезен редко, но в паре с `break` («выйти из цикла») — это идиома «крутись, пока не случится событие»:

```go
sum := 0
for {
    var x int
    fmt.Scan(&x)
    if x == 0 {
        break // 0 — сигнал остановки
    }
    sum += x
}
fmt.Println(sum)
```

Подробнее о `break` (и его брате `continue`) — на следующем уровне. Пока запомните: `break` немедленно прекращает цикл, выполнение продолжается после `}`.

## Счётчики и аккумуляторы

Два кита, на которых стоят почти все циклы:

- **Счётчик** — считает, сколько раз что-то произошло: `count++`.
- **Аккумулятор** (*accumulator*) — копит результат: `sum += x`, `product *= x`.

Главное правило: **объявить и обнулить ДО цикла**, изменять — ВНУТРИ:

```go
sum := 0                      // аккумулятор суммы
for i := 1; i <= 100; i++ {
    sum += i
}
fmt.Println(sum) // 5050 — Гаусс одобряет
```

Для произведения стартовое значение — `1`, а не `0` (иначе всё умножится в ноль):

```go
n := 5
fact := 1                     // аккумулятор произведения
for i := 2; i <= n; i++ {
    fact *= i
}
fmt.Println(fact) // 120 — это 5! (факториал)
```

## Читаем N чисел из ввода

Классическая связка для задач: сначала читаем количество, потом в цикле — сами числа. Заводить сто переменных не нужно — одна переменная `x` переиспользуется на каждой итерации:

```go
var n int
fmt.Scan(&n)

sum := 0
for i := 0; i < n; i++ {
    var x int
    fmt.Scan(&x)
    sum += x
}
fmt.Println(sum)
```

При вводе `3` и `10 20 30` программа напечатает `60`. Эта заготовка понадобится вам в задачах постоянно — запомните её как таблицу умножения.

## Off-by-one: ошибка на единицу

Самый популярный баг циклов в истории программирования — ошибка на единицу (*off-by-one error*): цикл выполняется на раз больше или меньше, чем нужно.

```go
// Хотели 5 итераций (1..5), получили 4:
for i := 1; i < 5; i++ { }   // 1, 2, 3, 4 — а 5 потеряли

// Хотели 5, получили 6:
for i := 0; i <= 5; i++ { }  // 0, 1, 2, 3, 4, 5 — лишняя
```

Два надёжных шаблона, чтобы не путаться:

| Что нужно | Шаблон | Итерации |
|---|---|---|
| ровно n раз | `for i := 0; i < n; i++` | 0, 1, …, n−1 |
| числа от 1 до n | `for i := 1; i <= n; i++` | 1, 2, …, n |

Сомневаетесь — прогоните цикл в голове для маленького n (например, 2) и посчитайте итерации на пальцах.

## Бесконечный цикл по ошибке

> [!WARNING]
> Если условие цикла никогда не станет ложным — программа зависнет. Три классических способа прострелить себе ногу:
>
> ```go
> for i := 0; i < 10; i-- { }   // i уходит в минус, i < 10 всегда истинно
>
> for i := 10; i > 0; i++ { }   // i растёт, i > 0 всегда истинно
>
> n := 10
> for n > 0 {
>     fmt.Println(n)            // забыли n-- : n вечно равно 10
> }
> ```
>
> На нашей платформе такую программу остановит таймаут (вы увидите ошибку «превышено время»), но привычку проверять, что счётчик действительно движется к выходу, стоит завести сразу.

Ещё одна коварная мелочь — точка с запятой сразу после заголовка:

```go
for i := 0; i < 5; i++ ; {   // ошибка компиляции:
    fmt.Println(i)            // syntax error: unexpected semicolon
}
```

А в форме-условии лишняя `;` превращает тело в пустое — компилятор скажет `unexpected {` или цикл молча провернётся вхолостую. Заголовок и `{` — на одной строке, без украшений.

## Циклы + условия = музыка

Внутри цикла можно (и нужно) использовать всё, что вы уже знаете — `if`, `switch`, `%`:

```go
for i := 1; i <= 10; i++ {
    if i%2 == 0 {
        fmt.Println(i, "— чётное")
    }
}
// 2 — чётное
// 4 — чётное
// 6 — чётное
// 8 — чётное
// 10 — чётное
```

А вот поиск максимума из потока чисел — приём, который пригодится в задаче со звёздочкой:

```go
var n int
fmt.Scan(&n)

var max int
for i := 0; i < n; i++ {
    var x int
    fmt.Scan(&x)
    if i == 0 || x > max {
        max = x // первое число — всегда новый максимум
    }
}
fmt.Println(max)
```

> [!NOTE]
> Почему `i == 0 ||`, а не просто стартовое `max = 0`? Если все числа отрицательные, ноль окажется «максимальнее» любого из них — и ответ будет неверным. Инициализация максимума первым элементом — приём, который спасает от этого классического бага.

## Запомнить

- В Go один цикл — `for`, но у него три формы: `for init; cond; post`, `for cond` (как while) и `for {}` (вечный).
- Ровно n раз: `for i := 0; i < n; i++`. От 1 до n: `for i := 1; i <= n; i++`.
- Аккумулятор объявляется до цикла: `sum := 0` для суммы, `fact := 1` для произведения.
- Читать n чисел: `for i := 0; i < n; i++ { fmt.Scan(&x) }`.
- Счётчик обязан двигаться к выходу из цикла — иначе программа зависнет.
- Ошибка на единицу лечится прогоном цикла в голове на маленьком n.

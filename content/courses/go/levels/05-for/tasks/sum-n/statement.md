Прочитайте целое число `n` (0 ≤ n ≤ 1000) — количество чисел. Затем прочитайте `n` целых чисел и выведите их сумму.

Если `n = 0`, выведите `0`.

Пример:

```
Ввод:  4
       3 1 4 1
Вывод: 9
```

> `fmt.Scan` не различает пробелы и переводы строк — числа можно читать по одному в цикле, как в уроке, независимо от того, как они разбиты по строкам.

Это главная задача уровня: связка «прочитать количество → цикл → аккумулятор» встретится вам ещё десятки раз.

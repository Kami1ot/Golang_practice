Прочитайте целое число `n` (1 ≤ n ≤ 1000), затем `n` целых чисел. Выведите наибольшее из них.

Числа могут быть **любыми** — в том числе все отрицательные.

Пример:

```
Ввод:  5
       3 7 2 9 4
Вывод: 9
```

Задача **со звёздочкой** — необязательная, но именно на ней ловится один из самых частых багов новичков. Подумайте: с какого значения должен стартовать максимум?

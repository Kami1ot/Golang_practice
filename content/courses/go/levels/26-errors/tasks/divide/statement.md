Разминка: первое честное деление.

Реализуйте функцию:

```go
func Divide(a, b int) (int, error)
```

Правила:

- `b == 0` — верните `0` и ошибку с текстом ровно `деление на ноль` (создайте через `errors.New`);
- иначе — целочисленное частное `a / b` и `nil`.

Пример работы:

```go
Divide(10, 2)  // 5, nil
Divide(7, 2)   // 3, nil — целочисленное деление
Divide(1, 0)   // 0, ошибка "деление на ноль"
```

Обратите внимание на порядок: сначала проверка опасного случая и ранний выход, потом спокойный счастливый путь. Тесты проверяют и значения, и текст ошибки, и `nil` при успехе.

Не меняйте имя и сигнатуру функции.

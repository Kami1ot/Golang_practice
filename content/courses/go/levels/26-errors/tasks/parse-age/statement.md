Основная задача: поле «возраст» приходит из анкеты строкой — превратите его в число со всеми проверками.

Реализуйте функцию:

```go
func ParseAge(s string) (int, error)
```

Правила:

- строка не является числом — пробросьте ошибку `strconv.Atoi` наверх как есть;
- число вне диапазона 0–150 — верните свою ошибку с текстом ровно
  `возраст 200 вне диапазона [0, 150]` (число — из входа, соберите через `fmt.Errorf`);
- иначе — возраст и `nil`.

Пример работы:

```go
ParseAge("33")   // 33, nil
ParseAge("сто")  // 0, ошибка от strconv.Atoi
ParseAge("200")  // 0, ошибка "возраст 200 вне диапазона [0, 150]"
ParseAge("0")    // 0, nil — границы входят в норму
```

Это упражнение на обе стороны идиомы: чужая ошибка пробрасывается без изменений (`return 0, err`), своя — создаётся на месте.

Не меняйте имя и сигнатуру функции.

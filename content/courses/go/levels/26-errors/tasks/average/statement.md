Задача со звёздочкой: обе стороны договора — функция, которая возвращает ошибку, и функция, которая её обрабатывает.

Реализуйте две функции:

```go
func Average(nums []int) (float64, error)
func Report(nums []int) string
```

`Average` считает среднее арифметическое:

- пустой (или nil) слайс — `0` и ошибка с текстом ровно `нет данных`;
- иначе — среднее и `nil`.

`Report` вызывает `Average` и превращает результат в строку:

- ошибка — `ошибка: <текст ошибки>`;
- успех — `среднее: <значение с одним знаком после запятой>` (глагол `%.1f`).

Пример работы:

```go
Average([]int{4, 5})   // 4.5, nil
Average(nil)           // 0, ошибка "нет данных"

Report([]int{4, 5})    // "среднее: 4.5"
Report([]int{})        // "ошибка: нет данных"
```

Здесь вся идиома целиком: внизу ошибку создают, наверху — проверяют через `if err != nil` и решают, что показать пользователю.

Не меняйте имена и сигнатуры функций.

Разминка: функция принимает что угодно — и опознаёт, что ей дали.

Реализуйте функцию:

```go
func Describe(v any) string
```

Правила опознания:

| Внутри | Результат |
|---|---|
| `int` | `целое: 42` |
| `string` | `строка: привет` |
| `bool` | `булево: true` |
| всё остальное | `неизвестный тип` |

Пример работы:

```go
Describe(42)      // "целое: 42"
Describe("го")    // "строка: го"
Describe(false)   // "булево: false"
Describe(3.14)    // "неизвестный тип"
```

Используйте type switch — `switch t := v.(type)`: в каждой ветке переменная уже имеет конкретный тип, и её удобно подставлять в `fmt.Sprintf`.

Не меняйте имя и сигнатуру функции.

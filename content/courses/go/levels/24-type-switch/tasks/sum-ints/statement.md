Основная задача: в куче разнотипных данных найдите и сложите только целые числа.

Реализуйте функцию:

```go
func SumInts(values []any) int
```

Она проходит по слайсу и суммирует **только** значения типа `int`. Всё остальное — строки, дробные, булевы, nil — молча пропускает. Пустой слайс — `0`.

Пример работы:

```go
SumInts([]any{1, "два", 3, 4.5, true, 10}) // 14 (1 + 3 + 10)
SumInts([]any{"го", 3.14})                 // 0
SumInts(nil)                               // 0
```

Подвох из урока: `4.5` — это `float64`, и в сумму он попасть не должен: assertion проверяет точный тип, а не «число вообще».

Функция не должна паниковать ни на каких входных данных — используйте безопасную ok-форму.

Не меняйте имя и сигнатуру функции.

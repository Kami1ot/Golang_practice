Задача со звёздочкой: теперь считаются ВСЕ числа — и целые, и дробные.

Реализуйте функцию:

```go
func Total(values []any) float64
```

Она суммирует значения типов `int` и `float64`, всё остальное пропускает. Результат — `float64`. Пустой слайс — `0`.

Пример работы:

```go
Total([]any{1, 2.5, "три", true}) // 3.5 (1 + 2.5)
Total([]any{10})                  // 10.0
Total(nil)                        // 0.0
```

Ловушка, ради которой эта задача существует: написать `case int, float64:` одной веткой не получится — в общей ветке переменная остаётся `any`, и складывать её нельзя. Нужны **отдельные** ветки, а в ветке `int` — конвертация `float64(n)` перед сложением.

Функция не должна паниковать ни на каких входных данных.

Не меняйте имя и сигнатуру функции.

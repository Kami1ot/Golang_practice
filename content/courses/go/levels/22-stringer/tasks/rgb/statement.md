Разминка: научите цвет красиво представляться. Дан тип:

```go
type RGB struct {
	R, G, B int
}
```

Сейчас `fmt.Println(RGB{255, 128, 0})` печатает безликое `{255 128 0}`. Реализуйте метод:

```go
func (c RGB) String() string
```

Он возвращает строку в CSS-формате: `rgb(255, 128, 0)` — компоненты через запятую с пробелом.

Пример работы:

```go
c := RGB{R: 255, G: 128, B: 0}
fmt.Println(c)        // rgb(255, 128, 0)
fmt.Sprintf("%v", c)  // "rgb(255, 128, 0)"
```

Как только метод готов, тип автоматически реализует `fmt.Stringer` — и весь пакет `fmt` начинает печатать цвет по-вашему. Для сборки строки понадобится `fmt.Sprintf` — добавьте `import "fmt"`.

Не меняйте объявление типа и сигнатуру метода.

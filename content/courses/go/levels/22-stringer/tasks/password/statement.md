Задача со звёздочкой: сделайте собственный тип ошибки с данными внутри.

Проверяем пароль на минимальную длину — 8 символов. Дан тип:

```go
type LengthError struct {
	Got, Min int
}
```

Реализуйте две вещи:

1. Метод `(e LengthError) Error() string` — сообщение строго в формате:
   `длина пароля 3, нужно не меньше 8` (числа — из полей `Got` и `Min`).
2. Функцию `CheckPassword(password string) error`:
   - пароль короче 8 **символов** — верните `LengthError` с заполненными полями (`Got` — фактическая длина, `Min` — 8);
   - иначе — `nil`.

Пример работы:

```go
err := CheckPassword("abc")
fmt.Println(err)               // длина пароля 3, нужно не меньше 8
CheckPassword("go-это-сила!")  // nil
```

Подвох: длину считаем в символах, а не в байтах — пароль `«пароль»` состоит из 6 букв, хотя `len` вернёт 12. Вспомните уровень про строки и руны.

Как только у `LengthError` появится метод `Error() string`, тип автоматически станет полноценной ошибкой — его можно возвращать как `error` без каких-либо объявлений.

Не меняйте объявление типа, имена и сигнатуры метода и функции.

Основная задача: длительность в минутах должна печататься по-человечески. Дан именованный тип:

```go
type Minutes int
```

Реализуйте метод `String() string` по правилам:

- меньше часа — только минуты: `Minutes(45)` → `45м`, `Minutes(0)` → `0м`;
- час и больше — часы и минуты, причём минуты **всегда двумя цифрами**: `Minutes(125)` → `2ч 05м`, `Minutes(60)` → `1ч 00м`.

Пример работы:

```go
fmt.Println(Minutes(45))   // 45м
fmt.Println(Minutes(60))   // 1ч 00м
fmt.Println(Minutes(125))  // 2ч 05м
fmt.Println(Minutes(600))  // 10ч 00м
```

Значения неотрицательные. Обратите внимание: `Minutes` — не структура, а именованный тип на основе `int`; часы и остаток минут достаются целочисленным делением. Для дополнения нулём пригодится глагол `%02d` из уровня про форматированный вывод.

Не меняйте объявление типа и сигнатуру метода.

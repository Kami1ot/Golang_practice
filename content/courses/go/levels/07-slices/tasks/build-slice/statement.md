Разминка на `append`. Прочитайте число `n` (0 ≤ n ≤ 100), затем `n` целых чисел. Соберите их в слайс и выведите две строки:

1. сам слайс — через `fmt.Println(nums)`;
2. его длину — через `len`.

Пример:

```
Ввод:  3
       1 2 3
Вывод: [1 2 3]
       3
```

`fmt.Println` печатает слайс в квадратных скобках с пробелами между элементами — именно такой формат и ожидается. При `n = 0` пустой слайс печатается как `[]`.

Реализуйте функцию `Reverse(nums []int) []int`, которая возвращает **новый** слайс с элементами `nums` в обратном порядке.

```go
Reverse([]int{1, 2, 3}) // [3 2 1]
Reverse([]int{7})       // [7]
Reverse(nil)            // []
```

Два условия:

- исходный слайс `nums` менять **нельзя** — верните новый (автотесты это проверяют!);
- не меняйте имя и сигнатуру функции — тесты ищут именно `Reverse(nums []int) []int`.

Эта задача — проверка главной идеи урока: слайс-параметр смотрит в ту же память, что и слайс вызывающего. Разворот «на месте» изменит данные того, кто вас вызвал.

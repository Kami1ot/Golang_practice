Разминка на карту-множество. Прочитайте `n` (0 ≤ n ≤ 1000), затем `n` целых чисел. Выведите, сколько среди них **различных** значений.

Пример:

```
Ввод:  5
       1 2 2 3 1
Вывод: 3
```

Различные значения здесь — `1`, `2` и `3`.

Вручную сравнивать каждое число с каждым не нужно: карта сделает всю работу — вспомните паттерн «множество» из урока.

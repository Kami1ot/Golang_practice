Реализуйте функцию `Count(nums []int) map[int]int`, которая возвращает карту частот: ключ — число из слайса, значение — сколько раз оно встретилось.

```go
Count([]int{3, 1, 3})  // map[1:1 3:2]
Count(nil)             // пустая карта (не nil!)
```

Требования:

- для чисел, которых нет в `nums`, ключа в карте быть не должно;
- для пустого (или nil) слайса верните **пустую карту, созданную через make**, а не nil;
- не меняйте имя и сигнатуру функции — тесты ищут именно `Count(nums []int) map[int]int`.

Это главный паттерн уровня — карта-счётчик. Он встречается везде: частота слов в тексте, подсчёт голосов, статистика покупок.

Прочитайте `n` (1 ≤ n ≤ 1000), затем `n` целых чисел. Выведите число, которое встречается **чаще всех**. Если таких несколько (ничья по частоте) — выведите **наименьшее** из них.

Пример:

```
Ввод:  7
       3 1 3 2 1 3 2
Вывод: 3
```

Тройка встретилась трижды — чаще всех.

Задача **со звёздочкой** и с подвохом: порядок обхода карты случаен, поэтому «взять первый подходящий ключ» будет выдавать разные ответы от запуска к запуску. Правило «при ничьей — наименьшее» делает ответ детерминированным — реализуйте его аккуратно.

# Карты (map) — данные по ключу

Слайс отвечает на вопрос «что лежит на позиции 3?». Но чаще нужен другой вопрос: «какой телефон у Алисы?», «сколько раз встретилось слово go?». Для пар «ключ → значение» в Go есть карта (*map*) — в других языках её зовут словарём (*dictionary*) или хеш-таблицей (*hash table*).

## Создание карты

Тип карты — `map[Ключ]Значение`. Два рабочих способа создать:

```go
// 1. Литерал — сразу с данными
age := map[string]int{
    "Алиса": 30,
    "Боб":   25,
}

// 2. make — пустая, готовая к записи
score := make(map[string]int)
score["го"] = 100
```

> [!WARNING]
> Третий способ — `var m map[string]int` — создаёт **nil-карту**, и это ловушка. Читать из неё можно, а вот запись роняет программу:
>
> ```go
> var m map[string]int
> fmt.Println(m["ключ"])   // 0 — чтение безопасно
> m["ключ"] = 1            // panic: assignment to entry in nil map
> ```
>
> Правило простое: собираетесь писать в карту — создавайте её через `make` или литерал `map[string]int{}`.

## Чтение, запись, длина

```go
m := make(map[string]int)
m["яблоки"] = 5           // запись
m["груши"] = 3
m["яблоки"] = 7           // повторная запись перезаписывает
fmt.Println(m["яблоки"])  // 7
fmt.Println(len(m))       // 2 — число пар ключ-значение
```

Чтение **несуществующего** ключа не паникует — возвращается нулевое значение типа (*zero value*): `0` для чисел, `""` для строк, `false` для bool:

```go
fmt.Println(m["ананасы"]) // 0 — ключа нет, но это не ошибка
```

## Ok-идиома: «а ключ вообще есть?»

Ноль из примера выше двусмысленный: то ли ананасов ноль штук, то ли про них вообще никто не слышал. Различить помогает вторая переменная:

```go
v, ok := m["ананасы"]
if ok {
    fmt.Println("есть в карте:", v)
} else {
    fmt.Println("такого ключа нет")
}
```

`ok` равно `true`, если ключ существует. Это настолько частый приём, что у него есть имя — ok-идиома (*comma ok idiom*). Компактная форма с if:

```go
if v, ok := m["яблоки"]; ok {
    fmt.Println("яблок:", v)
}
```

Часто нужен только факт наличия — значение отбрасываем через `_`:

```go
if _, ok := m["груши"]; ok {
    fmt.Println("груши в наличии")
}
```

## delete — удалить ключ

```go
m := map[string]int{"a": 1, "b": 2}
delete(m, "a")
fmt.Println(len(m))       // 1
delete(m, "нет-такого")   // удалять несуществующее безопасно: тишина, не паника
```

## range по карте — порядок СЛУЧАЕН

`range` выдаёт пары ключ-значение:

```go
m := map[string]int{"a": 1, "b": 2, "c": 3}
for k, v := range m {
    fmt.Println(k, v)
}
// b 2      ← при следующем запуске порядок может быть
// a 1      ← другим! Например: c 3, a 1, b 2
// c 3
```

> [!WARNING]
> Порядок обхода карты **специально** случаен — Go перемешивает его при каждом запуске, чтобы никто не привязывался к порядку. Отсюда два следствия:
>
> 1. Печатать карту целиком в задачах с проверкой вывода — плохая идея (вывод недетерминирован).
> 2. Если нужен предсказуемый результат (минимум, максимум, сумма) — вычисляйте его переменными-аккумуляторами, а не надейтесь на «первый элемент карты».

Кстати, `fmt.Println(m)` печатает карту с ключами, отсортированными для удобства — но полагаться на это в логике программы нельзя: сам `range` порядка не гарантирует.

## Карта-счётчик — главный паттерн уровня

Задача «сколько раз встречается каждое значение» решается картой в три строки:

```go
nums := []int{3, 1, 3, 2, 3, 1}
freq := make(map[int]int)
for _, x := range nums {
    freq[x]++          // ключа нет? m[x] вернёт 0, ++ сделает 1
}
fmt.Println(freq[3], freq[1], freq[7]) // 3 2 0
```

Магия в строке `freq[x]++`: для нового ключа чтение даст нулевое значение `0`, инкремент запишет `1`. Никаких проверок «а есть ли ключ» не нужно — нулевое значение работает на вас.

Тот же трюк с `map[значение]bool` отвечает на вопрос «какие значения встречались»:

```go
seen := make(map[int]bool)
for _, x := range nums {
    seen[x] = true
}
fmt.Println(len(seen)) // 3 — столько РАЗНЫХ чисел в nums
```

## Карты и функции

Как и слайс, карта передаётся в функцию «окном» — функция видит и меняет ту же карту:

```go
func Count(nums []int) map[int]int {
    freq := make(map[int]int)
    for _, x := range nums {
        freq[x]++
    }
    return freq
}

func main() {
    f := Count([]int{1, 2, 1})
    fmt.Println(f[1]) // 2
}
```

Функция, создающая и возвращающая карту, — стандартный строительный блок: снаружи остаётся только пользоваться результатом.

## Поиск «лучшего» по карте — аккуратно со случайным порядком

Найти ключ с максимальным значением можно, но помните про случайный порядок: при равных значениях «первый попавшийся» каждый запуск будет разным. Делайте выбор детерминированным — например, при равенстве берите меньший ключ:

```go
freq := map[int]int{4: 2, 1: 2, 7: 1}
best, bestCnt := 0, 0
first := true
for k, cnt := range freq {
    if first || cnt > bestCnt || (cnt == bestCnt && k < best) {
        best, bestCnt = k, cnt
        first = false
    }
}
fmt.Println(best) // 1 — у 4 и 1 по два очка, но 1 меньше
```

## Типичные ошибки новичка

| Код | Что случится | Как чинить |
|---|---|---|
| `var m map[string]int; m["a"] = 1` | `panic: assignment to entry in nil map` | создать через `make` или литерал `{}` |
| `if m["x"] == 0 { «ключа нет» }` | ноль не отличим от «нет ключа» | ok-идиома: `v, ok := m["x"]` |
| ожидание порядка в `range m` | порядок случаен, каждый запуск другой | аккумуляторы; правило разрешения ничьих |
| `len(m)` после `delete` «не изменился» | удаляли несуществующий ключ | `delete` молчит — проверьте ключ через ok-идиому |

## Запомнить

- `map[K]V`: создавать через `make(map[K]V)` или литерал; `var m map[K]V` — nil, запись в неё паникует.
- Чтение отсутствующего ключа — нулевое значение, без паники; «есть ли ключ» — ok-идиома `v, ok := m[k]`.
- `m[k] = v` пишет, `delete(m, k)` удаляет (молча, даже если ключа нет), `len(m)` — число пар.
- `for k, v := range m` — порядок обхода СЛУЧАЙНЫЙ, не полагайтесь на него.
- Счётчик частот: `freq[x]++` — нулевое значение делает проверки лишними.
- Множество «что встречалось»: `map[T]bool` + `len`.

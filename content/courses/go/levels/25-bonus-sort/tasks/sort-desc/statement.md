Разминка: рейтинг — лучшие сверху.

Реализуйте функцию:

```go
func SortDesc(nums []int)
```

Она сортирует слайс **по убыванию** — на месте, ничего не возвращая (как и положено сортировкам из пакета `sort`).

Пример работы:

```go
scores := []int{40, 95, 60, 95}
SortDesc(scores)
fmt.Println(scores) // [95 95 60 40]
```

Готовой функции «по убыванию» в пакете `sort` нет — соберите её из `sort.Slice` и своей less-функции. Повторяющиеся значения допустимы, пустой слайс — не ошибка.

Не меняйте имя и сигнатуру функции.

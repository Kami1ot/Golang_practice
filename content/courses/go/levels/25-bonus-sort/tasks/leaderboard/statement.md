Основная задача: соберите настоящую таблицу лидеров. Дан тип:

```go
type Player struct {
	Name  string
	Score int
}
```

Реализуйте функцию:

```go
func Rank(players []Player)
```

Она сортирует слайс на месте по двум ключам:

1. по очкам **по убыванию** — чемпион сверху;
2. при равных очках — по имени **по возрастанию** (алфавитный порядок).

Пример работы:

```go
players := []Player{
	{"Юра", 70},
	{"Аня", 90},
	{"Боря", 90},
}
Rank(players)
// [{Аня 90} {Боря 90} {Юра 70}]
// Аня и Боря набрали поровну — их упорядочил алфавит
```

Схема less-функции с запасным ключом есть в уроке — адаптируйте её: главный ключ здесь убывающий, запасной — возрастающий.

Не меняйте объявление типа, имя и сигнатуру функции.

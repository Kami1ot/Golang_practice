Задача со звёздочкой: сервис-счётчик с общим состоянием — и с конкурентными клиентами.

Реализуйте функцию:

```go
func NewCounter() http.Handler
```

Маршруты (стиль Go 1.22+, метод в шаблоне):

| Маршрут | Поведение |
|---|---|
| `POST /add` | тело — JSON `{"n": 5}`: прибавить `n` к счётчику, ответить статусом 200 (тело ответа не проверяется) |
| `GET /total` | JSON `{"total": 12}` с текущей суммой и заголовком `Content-Type: application/json` |

Правила:

- тело `/add` не декодируется как JSON → статус 400, счётчик не меняется;
- каждый вызов `NewCounter()` — независимый счётчик с нуля: состояние держите в замыкании или структуре, никаких глобальных переменных (тест создаёт два счётчика и проверяет, что они не мешают друг другу);
- сервер обрабатывает каждый запрос в своей горутине — сумму защищайте `sync.Mutex`: тесты бьют по `/add` из ста горутин разом и сверяют точную сумму.

Структуры для JSON (`addRequest`, `totalResponse`) и тип `counter` уже в заготовке. Понадобится import `encoding/json`.

Не меняйте имя и сигнатуру функции.

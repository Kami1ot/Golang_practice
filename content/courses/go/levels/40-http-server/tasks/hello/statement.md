Разминка: ваш первый хендлер — приветствие с параметром.

Реализуйте функцию:

```go
func HelloHandler(w http.ResponseWriter, r *http.Request)
```

Правила ответа:

- в запросе есть query-параметр `name` → написать `Привет, <name>!`;
- параметра нет или он пустой → написать `Привет, гость!`.

Пример работы:

```
GET /hello?name=Ада  →  Привет, Ада!
GET /hello           →  Привет, гость!
```

Статус не трогайте — 200 сервер поставит сам. Хвостовой перевод строки не важен: пишите через `fmt.Fprintf` или `fmt.Fprintln` — как удобнее.

Тесты вызывают хендлер напрямую — `httptest.NewRequest` + `httptest.NewRecorder`, как в уроке. Никакого `ListenAndServe`.

Не меняйте имя и сигнатуру функции.

Задача со звёздочкой: напечатайте чек — куда скажут.

Дан тип товара:

```go
type Item struct {
	Name  string
	Price int
}
```

Реализуйте функцию:

```go
func WriteReceipt(w io.Writer, items []Item)
```

Она записывает в `w` чек: по строке на каждый товар и итоговую строку с суммой. Формат — строго такой (каждая строка заканчивается `\n`):

```
- хлеб: 40 ₽
- молоко: 90 ₽
итого: 130 ₽
```

Правила:

- строка товара: `- <имя>: <цена> ₽`;
- последняя строка: `итого: <сумма всех цен> ₽`;
- пустой (или nil) список — только строка `итого: 0 ₽`.

Пример работы:

```go
var buf bytes.Buffer
WriteReceipt(&buf, []Item{{"хлеб", 40}, {"молоко", 90}})
fmt.Print(buf.String())
// - хлеб: 40 ₽
// - молоко: 90 ₽
// итого: 130 ₽
```

Не меняйте объявление типа, имя и сигнатуру функции.

Основная задача: соедините читателя с писателем и прокричите всё, что прочитали.

Реализуйте функцию:

```go
func Shout(r io.Reader, w io.Writer) error
```

Она читает **всё** из `r`, переводит текст В ВЕРХНИЙ РЕГИСТР и записывает результат в `w`:

- чтение сорвалось — верните полученную ошибку, ничего не записывая;
- всё получилось — верните `nil`.

Пример работы:

```go
r := strings.NewReader("говорите громче")
var buf bytes.Buffer

err := Shout(r, &buf)  // nil
buf.String()           // "ГОВОРИТЕ ГРОМЧЕ"
```

Понадобятся `io.ReadAll` для чтения и `strings.ToUpper` для регистра (он справляется и с кириллицей). Пустой источник — не ошибка: просто ничего не записывается.

Не меняйте имя и сигнатуру функции.

Машина собрана из двигателя: `Engine` встроен в `Car` без имени поля. Реализуйте два метода:

1. `(e Engine) Describe() string` — возвращает строку вида `двигатель 150 л.с.`, где число — из поля `Power`;
2. `(c Car) FullName() string` — возвращает строку вида `Gopher, двигатель 90 л.с.`: марка, запятая с пробелом, описание двигателя.

Пример:

```go
e := Engine{Power: 150}
e.Describe()   // "двигатель 150 л.с."

c := Car{Engine: Engine{Power: 90}, Brand: "Gopher"}
c.FullName()   // "Gopher, двигатель 90 л.с."
c.Describe()   // "двигатель 90 л.с." — метод продвинулся из Engine, Car получил его бесплатно
```

Требования:

- формат — символ в символ как в примерах: `л.с.` с двумя точками, запятая с пробелом после марки;
- в `FullName` пользуйтесь продвижением: поле `c.Power` и/или метод `c.Describe()` доступны без цепочки через `Engine` (хотя полное имя `c.Engine.Power` тоже никто не запрещал);
- не меняйте объявления типов, имена и сигнатуры методов — тесты рассчитывают именно на них.

Тесты проверяют в том числе, что `Describe` вызывается прямо у `Car` — это и есть продвижение метода из урока.

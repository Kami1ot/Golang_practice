Накопительный счёт построен на обычном: `Account` встроен в `SavingsAccount`, а `Rate` — процентная ставка (целое число: `10` значит 10%). Реализуйте два метода:

1. `(a *Account) Deposit(amount int)` — просто прибавляет `amount` к балансу, без какой-либо валидации;
2. `(s *SavingsAccount) AddInterest()` — начисляет проценты: увеличивает `Balance` на `Balance * Rate / 100` (деление **целочисленное**).

Пример:

```go
s := SavingsAccount{Rate: 10}
s.Deposit(200)         // Deposit продвинулся из *Account и работает у SavingsAccount
s.AddInterest()        // +200*10/100 = +20
fmt.Println(s.Balance) // 220
```

Суть задачи — прочувствовать, что метод с указательным получателем (*pointer receiver*) тоже продвигается: `s.Deposit(200)` меняет встроенный `Account` внутри `s`, и никакого дополнительного кода для этого писать не нужно.

Требования:

- не меняйте объявления типов, имена и сигнатуры методов — тесты рассчитывают именно на них;
- повторное `AddInterest` считает проценты уже от нового баланса (сложный процент);
- при `Rate = 0` баланс не меняется — это следует из формулы само собой.

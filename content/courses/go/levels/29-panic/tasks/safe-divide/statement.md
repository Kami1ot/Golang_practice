Основная задача: постройте защитную границу — как это делает веб-сервер вокруг обработчиков.

Реализуйте функцию с именованными результатами:

```go
func SafeDivide(a, b int) (result int, err error)
```

Правила:

- деление выполняйте «наивно» — `a / b` — и **не проверяйте** `b` заранее: в этой задаче панике разрешено случиться (в обычном коде вы бы, конечно, поставили guard — это была прошлая задача);
- поставьте `defer` с `recover`: пойманную панику превратите в ошибку с текстом
  `паника: <значение паники>` (глагол `%v`);
- при успехе — частное и `nil`.

Пример работы:

```go
SafeDivide(10, 2)  // 5, nil
_, err := SafeDivide(1, 0)
err                // ошибка "паника: runtime error: integer divide by zero"
```

Ключ к задаче — именованный результат `err`: после паники обычный `return` не выполняется, и вернуть ошибку наружу может только defer, записав её в именованную переменную.

Не меняйте имя и сигнатуру функции.

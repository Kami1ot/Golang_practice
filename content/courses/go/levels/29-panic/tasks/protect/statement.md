Задача со звёздочкой: предохранитель многоразового использования.

В прошлой задаче защита была прибита к делению. Сделайте её универсальной — для ЛЮБОЙ функции:

```go
func Protect(f func()) (err error)
```

Правила:

- вызовите `f()`;
- если она запаниковала — верните ошибку с текстом `паника: <значение паники>` (глагол `%v`; паника не должна вырваться из Protect);
- если отработала спокойно — верните `nil`.

Пример работы:

```go
Protect(func() { fmt.Println("всё тихо") })  // nil

err := Protect(func() { panic("взрыв") })
err  // ошибка "паника: взрыв"

err = Protect(func() { panic(42) })
err  // ошибка "паника: 42" — в panic передают что угодно
```

Это ровно тот приём, которым сервер защищается от паникующих обработчиков: чужой код выполняют внутри «предохранителя», превращающего любую панику в обычную ошибку. Функция-параметр — привет уровню про замыкания.

Не меняйте имя и сигнатуру функции.

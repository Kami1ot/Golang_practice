Основная задача: раздайте работу горутинам так, чтобы они не мешали друг другу.

Реализуйте функцию:

```go
func SquareAll(nums []int) []int
```

Она возвращает слайс квадратов: `res[i] == nums[i] * nums[i]`. Требования:

- квадрат **каждого** элемента считается в отдельной горутине;
- каждая горутина пишет только в свою ячейку заранее созданного слайса-результата;
- функция возвращается только после завершения всех горутин (`sync.WaitGroup`);
- порядок результата соответствует входу.

Пример работы:

```go
SquareAll([]int{3, 5, 7}) // [9, 25, 49]
SquareAll([]int{})        // []
```

Да, для квадратов трёх чисел горутины избыточны — здесь важен сам паттерн «свой слот на горутину»: замените возведение в квадрат на скачивание файла, и структура кода не изменится.

Не меняйте имя и сигнатуру функции.

Задача со звёздочкой: первый настоящий парный расчёт.

Реализуйте функцию:

```go
func HalfSums(nums []int) (int, int)
```

Она возвращает сумму **левой** половины слайса и сумму **правой** — посчитанные двумя горутинами одновременно:

- граница — `len(nums) / 2`: левая половина `nums[:mid]`, правая — `nums[mid:]` (при нечётной длине правая на элемент длиннее);
- каждую половину суммирует своя горутина, результат пишет в свою переменную;
- функция возвращается после завершения обеих (`sync.WaitGroup`).

Пример работы:

```go
HalfSums([]int{1, 2, 3, 4})    // 3, 7
HalfSums([]int{1, 2, 3, 4, 5}) // 3, 12 — нечётная длина: справа больше
HalfSums([]int{})              // 0, 0
HalfSums([]int{10})            // 0, 10 — левая половина пуста
```

Это ядро приёма «разделяй и властвуй» для больших данных: разбить массив, посчитать части конкурентно, объединить. На следующих уровнях вы научитесь собирать результаты через каналы — а пока хватит двух именованных слотов.

Не меняйте имя и сигнатуру функции.

Задача со звёздочкой: соберите фильтр строк — карманную версию утилиты `grep`.

Реализуйте функцию:

```go
func Grep(srcPath, dstPath, substr string) (int, error)
```

Она читает файл `srcPath` построчно и переносит в файл `dstPath` **только** строки, содержащие подстроку `substr` (каждую завершая `\n`). Возвращает число перенесённых строк.

Требования:

- источник — через `bufio.Scanner` (файлы бывают большими), приёмник — через `bufio.NewWriter`; про `Flush` не забудьте — иначе часть строк не доедет до диска;
- ни одна строка не совпала — в `dstPath` остаётся пустой файл, результат `0, nil`;
- исходного файла нет — верните `0` и ошибку открытия (сохраните исходную причину: как есть или обёрнутой через `%w` — тесты проверяют `errors.Is(err, fs.ErrNotExist)`);
- существующий `dstPath` перезаписывается.

Пример работы:

```go
// в app.log:
// [info] старт
// [error] диск полон
// [info] запрос
// [error] снова диск

Grep("app.log", "errors.log", "[error]") // 2, nil
// в errors.log теперь ровно две строки с [error]
```

Подстрока ищется через `strings.Contains` — регистр важен, совпадение в любом месте строки.

Не меняйте имя и сигнатуру функции.

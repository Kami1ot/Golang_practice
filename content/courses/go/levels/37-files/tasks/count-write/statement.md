Основная задача: две рабочие лошадки файлового мира — посчитать строки и записать строки.

Реализуйте две функции:

```go
func CountLines(path string) (int, error)
func WriteLines(path string, lines []string) error
```

**CountLines** возвращает число строк в файле `path`:

- файл читайте **построчно** через `bufio.Scanner` — не через `ReadFile`;
- файла нет или он не открылся — верните `0` и ошибку. Ошибку не подменяйте своей с нуля: исходная причина должна сохраниться (верните её как есть или оберните через `%w` — тесты проверяют `errors.Is(err, fs.ErrNotExist)`);
- пустой файл — `0` строк; последняя строка без завершающего `\n` тоже считается.

**WriteLines** записывает срез строк в файл `path`, каждую строку завершая `\n`:

- существующий файл перезаписывается с нуля;
- пустой срез — пустой файл (но файл создаётся);
- не забудьте про ошибки создания и про закрытие файла.

Пример работы:

```go
WriteLines("fruits.txt", []string{"яблоко", "груша", "слива"}) // nil
CountLines("fruits.txt")                                       // 3, nil
CountLines("нет-такого.txt")                                   // 0, ошибка (fs.ErrNotExist внутри)
```

Не меняйте имена и сигнатуры функций.

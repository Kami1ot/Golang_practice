Задача со звёздочкой: теперь данные отправляете вы — POST с JSON-телом и придирчивой проверкой ответа.

В заготовке объявлена структура:

```go
type User struct {
	Name  string `json:"name"`
	Email string `json:"email"`
}
```

Реализуйте функцию:

```go
func CreateUser(baseURL string, u User) (int, error)
```

Сценарий:

- превратите `u` в JSON (`json.Marshal`) и отправьте POST-запросом на `baseURL + "/users"` с Content-Type `application/json`; тело заверните в `bytes.NewReader`;
- сервер при успехе отвечает статусом `201 Created` и JSON-телом вида `{"id":101}`;
- статус не `201` (даже `200`!) — верните `0` и ошибку, в тексте которой есть код статуса;
- при успехе — верните `id` из ответа сервера.

Пример работы:

```go
id, err := CreateUser(srv.URL, User{Name: "Гоша", Email: "gosha@go.dev"})
// 101, nil
```

Тесты придирчивы по-взрослому: они проверяют не только результат, но и сам запрос — метод, заголовок `Content-Type` и JSON в теле, — ровно так тестируют клиентов в настоящих проектах.

Не меняйте имя и сигнатуру функции — и объявление `User` тоже.

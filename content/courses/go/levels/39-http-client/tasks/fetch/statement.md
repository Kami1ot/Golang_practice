Разогрев: научите программу скачивать текст по URL — с полным ритуалом вежливого HTTP-клиента.

Реализуйте функцию:

```go
func Fetch(url string) (string, error)
```

Правила:

- сделайте GET-запрос по `url`; не достучались до сервера — верните его ошибку как есть;
- не забудьте `defer resp.Body.Close()` (после проверки ошибки!);
- статус не `200` — верните пустую строку и ошибку, в тексте которой есть код статуса (например, `неожиданный статус: 404`);
- статус `200` — прочитайте тело **целиком** и верните строкой.

Пример работы (`srv.URL` — адрес тестового сервера):

```go
body, err := Fetch(srv.URL) // "привет, клиент!", nil

// а если сервер отвечает 404:
_, err = Fetch(srv.URL) // "", ошибка с "404" в тексте
```

Тесты поднимают локальный сервер через `httptest` — интернет не нужен. Среди проверок есть большое тело (сотни тысяч байт: дочитывайте до конца) и выключенный сервер (ошибка запроса должна дойти до вызывающего).

Не меняйте имя и сигнатуру функции.

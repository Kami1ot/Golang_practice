Основная задача: типичный поход в JSON-API — собрать URL, сходить, проверить статус, распарсить ответ.

В заготовке объявлена структура:

```go
type User struct {
	ID   int    `json:"id"`
	Name string `json:"name"`
}
```

Реализуйте функцию:

```go
func FetchUser(baseURL string, id int) (User, error)
```

Правила:

- запрос — GET на адрес `baseURL + "/users/<id>"`: для `id = 7` путь будет `/users/7` (соберите URL через `fmt.Sprintf`);
- не достучались — верните ошибку запроса как есть; тело не забудьте закрыть;
- статус не `200` — верните нулевого `User{}` и ошибку, в тексте которой есть код статуса;
- тело — JSON вида `{"id":7,"name":"Гоша"}`: декодируйте его в `User` прямо из `resp.Body` через `json.NewDecoder`; ошибку декодера верните как есть.

Пример работы:

```go
u, err := FetchUser(srv.URL, 7) // User{ID: 7, Name: "Гоша"}, nil

_, err = FetchUser(srv.URL, 99) // User{}, ошибка с "404" в тексте
```

Тестовый httptest-сервер знает нескольких пользователей, отвечает `404` на незнакомые id, а один из тестов подсовывает в ответ сломанный JSON.

Не меняйте имя и сигнатуру функции — и объявление `User` тоже.

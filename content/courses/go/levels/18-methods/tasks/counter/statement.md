Классика pointer receiver — счётчик, который копит состояние между вызовами. Дан тип:

```go
type Counter struct {
	value int
}
```

Реализуйте три метода:

- `(c *Counter) Inc()` — увеличивает счётчик на 1;
- `(c *Counter) Add(n int)` — изменяет счётчик на `n`; отрицательный `n` уменьшает счётчик — это нормально и так задумано;
- `(c Counter) Value() int` — возвращает текущее значение, состояние НЕ меняет.

Пример работы:

```go
var c Counter
c.Inc()
c.Add(10)
c.Add(-4)
c.Value()   // 7
```

Обратите внимание на получателей: `Inc` и `Add` меняют счётчик — им нужен указатель; `Value` только читает — ему хватает значения.

Не меняйте объявление типа, имена и сигнатуры методов — тесты вызывают именно `Inc`, `Add` и `Value`.

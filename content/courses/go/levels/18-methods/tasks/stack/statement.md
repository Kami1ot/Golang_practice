Соберите настоящую структуру данных — стек (*stack*): последним пришёл — первым ушёл (*LIFO*). Дан тип:

```go
type Stack struct {
	items []int
}
```

Реализуйте три метода:

- `(s *Stack) Push(x int)` — кладёт `x` на вершину стека;
- `(s *Stack) Pop() (int, bool)` — снимает верхний элемент и возвращает его со вторым значением `true`; для пустого стека возвращает `(0, false)` — та же ok-идиома, что у чтения из карты;
- `(s Stack) Len() int` — количество элементов в стеке.

Пример работы:

```go
var s Stack
s.Push(1)
s.Push(2)
s.Push(3)
s.Pop()    // 3, true — снимается последний положенный
s.Pop()    // 2, true
s.Len()    // 1
```

Договоримся: вершина стека — конец слайса `items`.

Не меняйте объявление типа, имена и сигнатуры методов — тесты вызывают именно `Push`, `Pop` и `Len`.

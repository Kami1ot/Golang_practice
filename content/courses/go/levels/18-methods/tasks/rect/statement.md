Разминка: прикрепите к прямоугольнику его первые «умения». Дан тип:

```go
type Rect struct {
	W, H int
}
```

Реализуйте два метода с получателем-значением (*value receiver*) — они только читают поля:

- `(r Rect) Area() int` — площадь: произведение сторон;
- `(r Rect) Perimeter() int` — периметр: сумма всех четырёх сторон.

Пример работы:

```go
r := Rect{W: 3, H: 4}
r.Area()       // 12
r.Perimeter()  // 14
```

Стороны неотрицательные; сторона может быть нулевой — тогда площадь равна 0, а периметр считается как обычно.

Не меняйте объявление типа, имена и сигнатуры методов — тесты ищут именно `r.Area()` и `r.Perimeter()`.

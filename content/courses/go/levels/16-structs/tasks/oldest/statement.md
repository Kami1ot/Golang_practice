В заготовке объявлён тип:

```go
type Person struct {
	Name string
	Age  int
}
```

Реализуйте функцию `Oldest(people []Person) string`, которая возвращает **имя самого старшего** человека в слайсе.

```go
Oldest([]Person{{Name: "Аня", Age: 20}, {Name: "Дед", Age: 74}}) // "Дед"
```

Правила:

- слайс `people` гарантированно **непустой** — проверка на пустоту не нужна;
- если самых старших несколько, верните имя **первого** из них (стоящего раньше в слайсе);
- не меняйте объявление типа `Person` и имя/сигнатуру функции `Oldest` — тесты ищут именно их.

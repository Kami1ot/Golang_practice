Кассовый аппарат подводит итог покупок. В первой строке — число товаров `n` (n ≥ 1). Далее `n` строк, в каждой — один товар: **название** (одно слово) и **цена** (целое число, может быть нулём — акция!).

Объявите тип `Item struct { Name string; Price int }`, соберите покупки в слайс `[]Item` и напечатайте две строки:

1. общую сумму чека;
2. название самого **дорогого** товара (если самых дорогих несколько — первого из них).

Пример:

```
Ввод:  3
       хлеб 40
       сыр 250
       чай 120
Вывод: 410
       сыр
```

40 + 250 + 120 = 410, самый дорогой — сыр за 250.

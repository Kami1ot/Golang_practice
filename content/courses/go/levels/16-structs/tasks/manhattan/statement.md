Программа читает одну строку с четырьмя целыми числами `x1 y1 x2 y2` — координатами двух точек.

Объявите тип `Point struct { X, Y int }`, соберите из прочитанных чисел две точки и напишите функцию `Dist(a, b Point) int`, возвращающую **манхэттенское расстояние** (*Manhattan distance*) между ними:

```
|x1 − x2| + |y1 − y2|
```

— столько кварталов прошагает таксист по городу с прямоугольной сеткой улиц, где ходить можно только вдоль осей. Напечатайте одно число — результат `Dist`.

Пример:

```
Ввод:  3 4 1 1
Вывод: 5
```

|3 − 1| + |4 − 1| = 2 + 3 = 5.

Модуль числа посчитайте своей вспомогательной функцией — `abs` вы уже писали на уровне про функции. Координаты могут быть отрицательными.

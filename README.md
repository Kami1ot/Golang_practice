# GoPractice

Локальная интерактивная платформа для изучения Go: курсы-деревья уровней,
уроки с примерами, тесты по теории, задачи с автопроверкой настоящим компилятором,
личный прогресс, ачивки и чат-наставник.

## Запуск

```powershell
go run ./cmd/server
go run ./cmd/server -addr 0.0.0.0:8080
```

Открыть: **http://127.0.0.1:8080** → зарегистрироваться.
**Первый зарегистрированный пользователь становится администратором.**

Требования: Go 1.22+, PostgreSQL (по умолчанию `postgres:root@localhost:5432`,
база `gopractice` создаётся и мигрируется автоматически).

## Флаги и окружение

| Флаг | Env | По умолчанию | Что делает |
|---|---|---|---|
| `-addr` | — | `127.0.0.1:8080` | адрес; для доступа из локальной сети — `0.0.0.0:8080` (разово согласиться в Windows Firewall) |
| `-dsn` | `GOPRACTICE_DSN` | `postgres://postgres:root@localhost:5432/gopractice` | PostgreSQL; `""` = всё в памяти |
| `-chat` | `GOPRACTICE_CHAT` | `auto` | наставник: `auto` / `api` / `off` |
| `-chat-model` | `GOPRACTICE_CHAT_MODEL` | `gpt-5.6-luna` | модель наставника |
| — | `OPENAI_API_KEY` | — | включает OpenAI-провайдера наставника |

## Чат-наставник

Отвечает на вопросы по теории и наводит на решение задач (никогда не решает за вас).
При запуске сервер загружает локальный `.env` (он исключён из Git), не
перезаписывая уже заданные переменные окружения. Скопируйте `.env.example` в
`.env`, укажите `OPENAI_API_KEY` и перезапустите сервер. Наставник использует
OpenAI Responses API с моделью `gpt-5.6-luna`; без ключа чат скрыт, а офлайн-
подсказки в задачах остаются доступны.

## Как это устроено

- Уровень открывается, когда пройдены все его предпосылки; пройден = тест сдан и
  обязательные задачи решены. Бонусные ветки не блокируют путь.
- Код проверяется настоящим `go build` + запуском на тест-кейсах или `go test`
  со скрытыми unit-тестами. Черновики сохраняются автоматически.
- Прогресс, ачивки и история чата — личные для каждого пользователя (PostgreSQL).
- Ачивки — в личном кабинете (клик по имени в шапке).

## Администрирование

Админ видит «Админку» в шапке: создание/редактирование курсов, уровней, уроков
(Markdown с превью), тестов (конструктор) и задач (включая скрытые тесты и подсказки).
Каждое сохранение проходит валидатор; при ошибке изменения откатываются, файлы
остаются нетронутыми. Контент — обычные файлы в `content/` (см. [AUTHORING.md](AUTHORING.md)).

План наполнения курсами: [ROADMAP.md](ROADMAP.md).

## Безопасность (домашний инструмент)

Пароли хэшируются bcrypt, сессии — HttpOnly-cookie. Трафик по локальной сети —
HTTP без шифрования: не используйте пароль от чего-то важного.

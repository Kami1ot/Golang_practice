# GoPractice — интерактивная платформа обучения Go

Локальное веб-приложение: пользователи учат Go, проходя курсы-деревья (DAG уровней).
Уровень = урок (Markdown) → тест по теории → задачи по коду с автозапуском и проверкой.
Курсы пишутся как файлы данных (см. AUTHORING.md) — Codex'ом или через веб-админку.
План наполнения курсами — ROADMAP.md (отмечать заведённые уровни!).
Идеи и спеки будущих фич — в ideas/ (CI/CD + мультиязычность, workspace-редизайн уровня).

**Структура контента: ОДИН курс `go` («Язык Go»)**, уровни сгруппированы в секции
через поле `group` в level.json («Основы», «Циклы и коллекции», …) — карта рисует
подписи-разделители. Отдельные курсы — только для других больших тем (другой язык).
Стандарт глубины уровня — в AUTHORING.md (урок 180-300 строк, тест 6-7 вопросов,
3 задачи с подсказками). Секции 1-4 (уровни 01-20, по «Структуры и указатели») заведены и проверены.

Единственный админ: Kamilot (аккаунт пользователя; пароль его собственный).

Чат-наставник ждёт установки Codex CLI пользователем:
`irm https://Codex.ai/install.ps1 | iex` + разовый интерактивный логин `Codex`.
После этого перезапустить сервер — провайдер подхватится автоматически (режим auto).

## Грабли, уже собранные (не наступать повторно)

- `content/` содержит собственный `go.mod` (модуль gopractice-content) — иначе `go build ./...`
  пытается собрать starter.go учебных задач и падает. НЕ удалять этот файл.
- PowerShell портит кавычки в `curl.exe -d '...'` — JSON-тела слать через файл: `--data-binary "@file.json"`.
- PowerShell 5.1 показывает UTF-8-файлы без BOM кракозябрами — это глюк отображения,
  файлы корректны; смотреть с `-Encoding utf8`.
- Уровень без теста и задач завершается ТРАНЗИТИВНО (completedSet в dto.go):
  только когда завершены все его предпосылки.
- Классификатор Codex блокирует `iex` удалённых скриптов — установку CLI делает пользователь.
- CSS с `display:flex` на элементе перебивает атрибут hidden — для таких классов нужно
  явное правило `.x[hidden]{display:none}`.
- Статика отдаётся с `Cache-Control: no-cache` (noStaleCache в server.go) — иначе Chrome
  по эвристике кэша показывает старые css/js после правок.

## Команды

```powershell
go run ./cmd/server          # запуск: http://127.0.0.1:8080
go test ./...                # все тесты (runner ~30 сек, store требует Postgres)
go build ./...               # проверка компиляции
```

**После проверок глушить ВСЕ запущенные серверы** (требование пользователя): включая
сирот `server.exe` из go-build-кэша (переживают обёртку preview). Порты 8080/8081
должны остаться свободными — свой сервер пользователь запускает сам.

Флаги сервера: `-addr` (LAN: `0.0.0.0:8080`), `-content`, `-web`, `-dsn`,
`-chat auto|api|cli|off`, `-chat-model`. Env: `GOPRACTICE_DSN`, `GOPRACTICE_CHAT`,
`GOPRACTICE_CHAT_MODEL`, `ANTHROPIC_API_KEY`.

Проверка API из PowerShell: **только `curl.exe`**. Почти всё API требует сессию:
```powershell
curl.exe -c cookies.txt -X POST http://127.0.0.1:8080/api/auth/login --data-binary "@login.json"
curl.exe -b cookies.txt -X POST http://127.0.0.1:8080/api/reload   # reload — только админ
```

## Архитектура

Один Go-бинарник (`cmd/server`). Зависимости: `jackc/pgx/v5`, `golang.org/x/crypto`,
`anthropics/anthropic-sdk-go`.

- `internal/content` — загрузка и валидация курсов (DAG, id≠папка, hints); пустой курс/каталог допустимы (для админки)
- `internal/runner` — проверка решений: `go build -o prog.exe` → запуск exe с context-таймаутом (НЕ `go run`), capped 256 КБ, cleanup с ретраями, pre-warm
- `internal/store` — PostgreSQL: только сырые факты per-user (прогресс, users/sessions, chat_messages, выдачи ачивок); всё производное вычисляется
- `internal/auth` — bcrypt + токены сессий (чистые функции)
- `internal/chat` — провайдеры наставника: api (официальный SDK, opus-4-8 adaptive) и cli (`Codex -p`, семафор 1, таймаут 120с), выбор в auto.go
- `internal/httpapi` — REST, middleware requireUser/requireAdmin, админ-CRUD (admin.go + adminfs.go), ачивки (achievements.go), чат (chat.go)
- `web/` — SPA без сборки: роутер с auth-гвардом, views/, views/admin/, vendor

## Инварианты (не нарушать)

1. **Ответы никогда не уезжают ученикам**: quiz answer/answers/explanation вырезаются в DTO;
   main_test.go и скрытые тест-кейсы недоступны через публичное API и /content/ (whitelist картинок).
   Сырые данные с ответами ездят ТОЛЬКО по /api/admin/* под role=admin.
2. **В промпт чат-наставника никогда не попадают** ответы теста, скрытые тест-кейсы, main_test.go —
   только урок, условие, заготовка и черновик ученика (тест TestChatPromptSafety это стережёт).
3. Прогресс/ачивки в БД — только факты в разрезе user_id; замки/XP/условия ачивок вычисляются.
4. **Мутации content/ — только через /api/admin/* под fsMu** (снапшот → запись → валидация → откат при
   ошибке). Ручное редактирование файлов + POST /api/reload (админ-cookie) по-прежнему законно.
5. Сравнение вывода — через общий `normalize()` (io-задачи и quiz-`output`).
6. Сервер по умолчанию слушает 127.0.0.1; LAN — осознанный флаг -addr.
7. Первый зарегистрированный пользователь = админ и усыновляет прогресс-сироты (user_id IS NULL).
